# ADR-0146: 回転時のエルボー trunk 追従 (バグ修正)

## 状態

実装済み (v1.7.203)。

## 背景

`s.bend` はエルボー trunk の**ワールド座標**。`_rotPtsAbout`
(キーボード ,/.) と `_rotShape` (回転ノブのグループ回転) は
端点 x1/x2 と way を回すが bend を触らなかった — 回転後の
trunk が盤面の旧位置に取り残され、elbow が破綻していた。

## 決定

- 新ヘルパ `_rotBend(s,tr,rot)`: 回転前の trunk 線分を評価し、
  その両端点をコネクタと剛体回転させる。回転後も軸平行なら
  対象座標を再導出し、斜め (90°倍数でない) なら表現不能の
  ため `null` (自動中央) にフォールバック。
- `_rotPtsAbout` は端点変異**前**に trunk を捕捉 (tr は回転前
  ワールド座標)、`_rotShape` は `orig` から評価。
- `cbend` (弦法線上の相対オフセット) と `labelPos` (経路 t)
  は回転不変のため対象外。

## 断念した代替案

- **常に null にクリア**: 90°/180° では完全に表現可能なのに
  手動調整を捨てるのは過剰。
- **bend を点に持ち替える再設計**: 既存 op 形式の互換性を壊す。

## 影響

- 回転しない elbow には無影響。非軸平行回転は bend が自動位置
  に戻るのみ (elbow 経路自体は保持)。
