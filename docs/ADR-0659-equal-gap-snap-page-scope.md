# ADR-0659: 等間隔スナップを可視・現ページ図形に限定

## Status
Accepted — round407

## Context
`_eqGapSnap` (ドラッグ中の等間隔吸着、ADR-0071) は `_sh()` を全走査し、**非表示図形と別ページの図形も「間隔の作り手」として扱っていた**。ドラッグ中に見えない幾何へ吸着するため、ユーザーには理由不明なジャンプとして観測される。

同種の `_snapIndex` (エッジ/中央スナップ、ADR-0153) は `exclFn(s)||_hd(s)||!_pgOk(s)` で既に除外済み — `_eqGapSnap` は ADR-0646 多ページ化の追従漏れ。

## Decision
`_eqGapSnap` の候補ループに同じ述語を適用:

```js
if(excl(s)||_hd(s)||!_pgOk(s))continue;
```

## Consequences
- ドラッグ中の吸着は「今見えているページの、可視図形」にだけ発生 — 吸着とガイドが必ず可視幾何と一致
- 単一ページ・全可視の盤面では従来通り

## Tests
- 別ページ図形はギャップを形成しない (behavioural)
- 非表示図形も同様 (ADR-0153 parity)
- フィルタ述語のソースピン
