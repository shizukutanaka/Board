# ADR-0219: ⌥ (Alt) で中心基点の図形描画

## 状態

実装済み (v1.7.277)。

## 背景

rect/ellipse/diamond/sticky/frame のドラッグ描画は常に
左上→右下方向だった。Figma / draw.io / Keynote では
⌥+ドラッグでアンカーを中心にした描画 (対称に拡大) が
慣例で、中心が決まっている図形の作図に必須。

## 決定

`contRectLike` に `center` 引数を追加し `e.altKey` を配線。
中心モードでは絶対値の半分をアンカーから両側に張り出す
(`x=cx-|dx|`, `w=2|dx|`)。⇧ との組合せ (中心+正方形/真円)
も自然に動く。

## 断念した代替案

- アンカー中心モードを別ツール化: 修飾キー慣例と衝突し、
  UI が増えるだけ。

## 影響

- 描画中の ⌥ は他機能と競合なし (選択ツールの複製/ラッソは
  select ツール時のみ)。
- endRectLike の click-stamp (2px 未満) は中心モードでも
  アンカー中心にデフォルトボックスを置く既存動作のまま。
