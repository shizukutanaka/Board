# ADR-0609: フォーカス中の docName input をリモート改名が上書きしない

## 状態
実装済 (v1.7.636)

## 背景
`_setDocName` は `state.docName` 更新と同時に `d.value=_dn()` で input の
表示を常に書き換えていた。コラボ中にリモート `name` op (LWW 受理) や
インポートによる改名が、**ユーザーが #docName をタイプしている最中**
(IME 合成中含む) に到着すると、打ち込み中の文字列が外部値で上書きされる。

その後ユーザーが `input`/`blur` で `_commitDocName` すると残りの文字が
送信されるので、プレフィックス消失・表示のチラつきという形で表面化する。

## 決定
- `_setDocName`: `d!==document.activeElement` のときのみ `d.value` を
  書き換える。フォーカス中は `state.docName` + タイトルだけを更新し、
  ユーザーのタイピングは保持
- `blur` リスナーで `docNameEl.value=_dn()` — 編集終了後に表示を
  LWW 解決済みの名前へ同期

タイピングのコミットは常にローカル ts が新しいので LWW でそのまま勝つ
ことが多いが、仮にリモート値が残る場合でも blur 後の表示は必ず解決値。

## 影響
- リモート改名による入力消失・IME 合成の破壊を防止
- 解決順序は ADR-0581 の ts ベース LWW をそのまま尊重
