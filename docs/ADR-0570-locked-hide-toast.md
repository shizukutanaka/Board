# ADR-0570: 全ロック選択への hide でトースト

## 状態
実装済み (v1.7.597)

## 背景
`hideSelection` は `_forSel` 内で `_lk`/`_hd` をスキップするため、選択が
全てロック済み (または非表示) のとき `before` が空になり、⌘⇧H が
完全に沈黙していた。doDelete は同状況で `lockedNoop` トーストを出す
(ADR-0396) ので非対称だった。

## 決定
hide も同じ慣例に揃える: `before` が空かつ選択非空なら `_wT('lockedNoop')`。
新規 i18n キーは追加しない (既存キー再利用)。

## 影響
- locked-only 選択での ⌘⇧H が「ロック済み — ⌘⇧L で解除」を表示
