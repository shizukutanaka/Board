# ADR-0592: グループハローは可視メンバーのみで包絡する

## 状態

実装済 (round301)。

## 背景

グループハロー (drawOverlay の点線枠) は `_grpMapGet` が `groupId` ごとの全メンバー
を集め、その union bbox を描いていた。`visible:0` のメンバーが存在しても除外されず、

- 全メンバー非表示のグループ → 見えない内容の位置にハローが残る (リーク)
- 一部非表示 → ハローが空の領域まで膨らむ

という、ピア選択アウトラインを hidden 図形に描かなかった ADR-0576 と同型の穴だった。

## 決定

`_grpMapGet` の集約を `_gi(s) && !_hd(s)` に限定 — 可視メンバーのみ包絡に含め、
全メンバー非表示のグループにはハローを描かない。メンバー自体の `groupId` は保持
(再表示でハローが戻る)。

## 影響

- 不可視コンテンツが halo 経路で位置をリークしない (hidden parity)。
- `_grpMapGet` の唯一の consumer は halo 描画のため影響範囲は限定的。
- テスト: 一部非表示では可視メンバーのみ、全非表示ではエントリ空であることを assert。
