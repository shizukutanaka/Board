# ADR-0135: ビュー系トグルの ctx メニュー項目

## 状態

実装済み (v1.7.192)。

## 背景

グリッド (G)・吸着 (⇧G)・ミニマップ (M)・フィット (⇧1)・ズーム
リセット (⌘0) はキーボード限定 — タッチでは到達不能
(ADR-0134 の検索と同じ FT-06 パターン)。

## 決定

- `toggleGridView()` / `toggleSnapMode()` にインライン実装を
  切り出し、ctx に5項目追加: 全体を表示 (⇧1) / ズーム100% (⌘0) /
  グリッド (G) / 吸着 (⇧G) / ミニマップ (M)。
- ビュー系は選択と独立なので常時表示 (ctxSearch と同じ群)。

## 断念した代替案

- **設定パネルの新設**: 5個のトグル専用パネルはオーバーヘッド —
  既存 ctx メニューの1群で十分。

## 影響

- キーバインドの動作は不変 — 同じ関数を2経路から呼ぶだけ。
