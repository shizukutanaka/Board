# ADR-0186: フレームラベル/ラベルエディタが s.font を反映

## 状態

実装済み (v1.7.244)。

## 背景

ADR-0173 の書体サポートで text/sticky/全ラベルに `_fontFam` が通ったが、
フレームラベル (常に 600 weight のキャプション) とラベル編集エディタ
が `system-ui,sans-serif` 固定のまま残った — ラベル付きフレームに
cycleFont を効かせても描画が追随しない。

## 決定

フレームラベルの canvas/SVG 両描画でフォントファミリを
`_fontFam(s)` に。ウェイト 600 の見た目規約は維持 (s.bold を
読まない) — ファミリのみ継承。ラベルエディタの input フォントも
`_fontFam(hit)` に揃え、編集と描画の見た目を一致させる。

## 断念した代替案

- **600 も s.bold 化**: フレーム名は常に太字キャプションという
  視覚階層の約束を壊す。

## 影響

- s.font 無指定時は不変。ラベル付きフレームで cycleFont が完結する。
