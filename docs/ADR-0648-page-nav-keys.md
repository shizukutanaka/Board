# ADR-0648: PgUp / PgDn ページナビ

## 状況
ADR-0646 の `pgBar` はマウス/ポインタ専用 UI — キーボードだけの操作や
スクリーンリーダー利用ではページを切り替える経路が無かった。Board は
全機能をキーボード到達可能にする方針 (Enter 編集、Tab サイクル、ctx キー
巡回) なので a11y の穴になっていた。

## 決定
`PageUp` / `PageDown` でページを巡回する (修飾キー不要)。

- グローバル keydown ハンドラ (`_KD`) の ⌘A 直後:
  `!meta && (k==='pagedown'||k==='pageup') → _pgNav(±1)`。
  修飾キーを要求しない — スライド系 (PowerPoint/Keynote/Google
  Slides) と同じ、修飾なしのページ移動が最も発見しやすい。
  input/textarea フォーカス中は `e.target.matches('input,textarea')` の
  既存ガードで入力側に渡る (PgUp/PgDn がテキストスクロールを奪わない)。
- `_pgNav(d)`: `(i+d+n) % n` でループ — 末尾の次は先頭へ戻る
  (タブ巡回と同じラップ動作)。`_pgOn()` 不成立の単一ページ盤面では no-op。
- アナウンスは `switchPage` 既存の `_ann(page.name)` がそのまま効く —
  SR ユーザーには「どのページに移ったか」が読み上げられる。
- ヘルプ (?) のショートカット一覧に `PgUp / PgDn` 行を追加。

## 非目標
ページの直接ジャンプ (⌘2→ページ2 等)、ページ一覧ポップオーバー、
ドラッグ並べ替え。`PgUp`/`PgDn` は巡回のみ — ページ数は 64 上限だが
巡回コストは O(1) で問題にならない。
