# ADR-0096: リサイズ時の等サイズスナップ

## 状態

実装済み (v1.7.154)。

## 背景

`resizeSnap` はドラッグ中の辺を他図形のエッジに吸着するのみ —
「あの図形と同じ幅/高さに揃える」が手動目視頼み。draw.io の
スマート寸法ガイド相当。

## 決定

- `resizeSnap` の末尾 (edge スナップ後) に寸法スナップを追加:
  - ハンドルから導出した新 `w`/`h` (e→`x-orig.x`、w→`orig.x+orig.w-x`
    ほか) が他図形の `w`/`h` と `SNAP_OBJ` 許容内なら一致側へ吸着。
  - ガイドは対象図形の該当辺 (等幅→底辺、等高→左辺) に沿って描画。
  - ターゲットは `_snapIndex` の `b` 参照から重複なしで回収
    (選択除外は索引側で済み)。
- `state.snap`(グリッド)・`rotate`・`p1/p2` ハンドル時は従来通り
  早期 return — lock(⇧)/alt(⌥) も resizeSnap 自体が呼ばれないため
  競合なし。

## 断念した代替案

- **applyResize 内でのスナップ**: ハンドル数学の二重化を招く。
  resizeSnap が既に handle+orig を持つのでそこで完結。
- **寸法ラベルの描画**: ガイド線のみ — 数値表示は読み辛い+実装重い。

## 影響

- 同幅/同高揃えがドラッグ1操作で可能に。
- edge スナップと共存 (寸法ヒットが x/y を上書き、ガイドは両方出る)。
