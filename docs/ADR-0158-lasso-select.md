# ADR-0158: Alt+ドラッグのフリーハンド・ラッソ選択

## 状態

実装済み (v1.7.216)。

## 背景

矩形マーキーでは取りこぼす配置がある — 斜めに重なった図形群、
間を他図形が通る散配置など。draw.io / Miro の lasso が欠けて
いた (Excalidraw にも無い機能だが密度の高い盤面で有用)。

## 決定

- **⌥+空ドラッグ = lasso**。Alt+ドラッグは従来「図形上で開始
  すると複製 (ADR-0060)、空で始めると通常マーキー」だった —
  空キャンバス上の ⌥ を lasso に割当て、修飾子の衝突なし。
- `ptr.dragKind='lasso'`、`ptr.lasso=[wp…]` を積み増し、
  `state.lasso` (render-only) に共有して破線ポリゴン+薄塗り。
- コミットは `_ptInPoly` (even-odd ray cast) で各図形の **bbox
  中心**を判定 (draw.io ルール) — 端が触れるだけでは選ばない、
  「囲んだもの」という直感に一致。ロック・非表示は除外、
  ⇧ で加算選択 (marquee parity)。
- Esc/ジェスチャリセット/pointerdown の ephemeral リセット経路
  で `state.lasso=null`。
- help グリッドに `⌥ + drag` 行、i18n `lasso` ja/en。

## 断念した代替案

- **専用ツールボタン**: 単一ファイルでツールバーは既に密集。
  ⌥ は複製と同じ修飾子で「空所のみ発火」により衝突しない。
- **図形の全頂点包含ルール**: 回転図形の角が図形中心を外に
  持つケースで選びにくい — 中心判定で十分一貫。

## 影響

- 選択ジェスチャのみ。描画はオーバーレイ、undo/共有に無関係。
