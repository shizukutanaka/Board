# ADR-0209: コネクタ端点の固定エッジアンカー

## 状態

実装済み (v1.7.267)。

## 背景

結合端点は常にフローティング — `_edgePt` が相手図形方向へエッジ
接触点を毎フレーム再計算するため、図形を動かすと接続点がエッジ
上を滑って回り込む。draw.io の `exitX/exitY` 固定アンカー相当
(「右辺の 30% の点から出る」等の確定的な配線) が無かった。

## 決定

`⌥`+ドロップで結合 → `s.aF/s.bF={fx,fy}` (結合先 bbox の分数座標)
を記録し、`connEnds` は `_edgePt` の代わりに
`{x:bb.x+bb.w*fx, y:bb.y+bb.h*fy}` を返す。ドロップ点の分数は
最近接エッジへクランプ (短い方の軸を 0/1 に固定) — 常に周上に
アンカーが乗る draw.io 互換の配置。⌥無しドロップは従来通り
フローティング (`sh[fk]=null`)。形状変換は bbox 分数なので追従。
- `_endPointBind(sh,handle,alt)` に altKey を配線
- `applyResize`: 掴んだ時点で `sh[bk+'F']` も解放
- `reverseConn`/`unbindSelection`/del カスケード: aF/bF を
  交換・クリア (before/after 含む)

## 断念した代替案

- **アンカーを図形内部にも許可**: 線が塗りの下に消えて見えるため
  周上クランプに統一 (draw.io も実質エッジ配置)。

## 影響

- 固定アンカー経路は「どの辺のどの位置から出るか」が確定する
  ためフローチャートの配線が安定。既存ボードは aF/bF 無しで
  フローティング挙動のまま不変。
