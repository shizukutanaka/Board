# ADR-0614: 並行 'replace' の勝者を clockNewer 全順序で一意化

## 状態
実装済 (v1.7.641)

## 背景
ADR-0613 で 'replace' が wire 収束するようになったが、**2ピアが同時に
全置換をコミット**するケースが未定義のまま残った: 各ピアが互いの swap を
受信して適用すると、A→B を送った側は B を、A→C を送った側は C を保持 —
交差して発散する。到着順に依存する「最後勝ち」では第三ピアの受信順が
逆転した場合に分裂するため、決定的な勝者規則が必要。

## 決定
`state._lastRep` に「最後に適用した 'replace' の clock」を保持
(`_apply` の 'replace' case が記録 — ローカル commit・リモート適用・undo
全てを通る)。`applyRemote` で、到着した swap が `_lastRep` より新しくない
(`clockNewer` で負ける) 場合は棄却:

- 両ピアが同時コミット → ts 大きい方が全ピアで勝つ (peer 文字列が
  ts 同値のタイブレーク、seq が最終決定) — 到着順・受信順に無関係に収束
- 同一 op の再送は dedup で既に棄却、等 clock は `clockNewer` false で二重適用も防止
- undo の backward 適用でも `_lastRep` は op の clock を維持 — 元に戻した
  盤面より古いリモート swap は依然棄却 (復元した状態が意図)

## 影響
- 同時 import の収束先が全ピアで一意 (ADR-0613 の補完)
- 制限: 混在バージョン部屋では旧ピアが「最後勝ち」で動くため、
  新版側の一意勝者と食い違い得る — 混在期間のみ
