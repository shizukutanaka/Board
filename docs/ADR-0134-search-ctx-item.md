# ADR-0134: 検索ボックスの ctx メニュー項目

## 状態

実装済み (v1.7.191)。

## 背景

図形検索 (⌘F) はキーボード限定 — `sqinput` 自体は動的生成で
ボタンも無く、タッチでは長押しメニュー (ADR-0006) が唯一の
到達経路だった。FT-06 が警告した「キーボード限定機能」罠の残存例。

## 決定

- ⌘F のトグルを `toggleSq()` に切り出し、ctx「検索」からも呼ぶ。
- 検索はボードレベルの動作なので選択の有無に関わらず常時表示。

## 断念した代替案

- **検索ボタンの常設**: ツールバーは既に密集 — ctx 1項目で済む。
- **ctxBring*/ctxSend* の z-order 項目の新設**: 実装済みと判明した
  ため同テーマ (タッチ未到達のキー操作) の検索に差替。

## 影響

- ⌘F の動作は `toggleSq()` に集約され不変 — ctx は別経路の追加。
