# ADR-0130: ⇧マーキーで加算選択

## 状態

実装済み (v1.7.187)。

## 背景

マーキー確定が無条件に `selection.clear()` — ⇧+ドラッグでも既存
選択が消える。Figma/draw.io の「⇧マーキー = 選択に加算」が無い。

## 決定

- `endSelect` のマーキー確定で `if(!shift)state.selection.clear()`
  — ⇧中は既存選択を保持してヒットを追加。

## 断念した代替案

- **⇧マーキーの交差モード切替**: 方向 (ADR-0124) と修飾は直交 —
  右→左⇧ドラッグは「交差で加算」として自然に組み合わさる。

## 影響

- 複数領域に跨る選択がキーボード無しで組める。
