# ADR-0583: コネクタ反転で labelPos を経路パラメータに沿ってミラーする

## 状態

実装済 (round292)。

## 背景

`flipShape` は図形の水平/垂直反転を行う。コネクタの経路関連プロパティは既に揃っていた:

- `way` (ウェイポイント) — 反転軸に沿って座標をミラー (ADR-0090)
- `bend` (エルボー trunk 位置) — 反転軸に沿ってミラー (ADR-0133)
- `cbend` (曲線の垂直オフセット) — 符号反転してカイラリティを保持 (ADR-0132)

一方 `s.labelPos` はラベルの経路パラメータ `t` (0..1、x1→x2 の方向) だが**未変換**だった。反転で x1/x2 の見た目上の位置が入れ替わると、ラベルは鏡写し先の「逆側」の t 位置に現れ、反転前に start 端に置いたラベルが end 端へ移ってしまう。

## 決定

`flipShape` で `s.labelPos = 1 - s.labelPos` とする。

数学的には、点 `p(t) = x1 + (x2-x1)·t` のミラー像は `m(p(t)) = m(x1) - (x2-x1)·t` で、新経路 `p'(t') = m(x1) + (m(x2)-m(x1))·t'` 上で `t' = 1-t` に一致する。したがって `1-t` への変換で「ラベルが経路上の同じ見た目の位置に留まる」ことが保証される。

実装は `cbend` の隣 (経路プロパティのミラー処理と同じ箇所) に1行追加するのみで、値の型も範囲も変わらないためバリデーション (ADR-0367/0369 の `labelPos` 数値チェック) はそのまま通る。

## 影響

- 修正は1行 + テスト2件 (ソースピン + 振る舞い: `doFlip('h')` で 0.2→0.8 を assert)。
- `labelPos` が未設定 (midpoint 既定) のコネクタは `null` ガードで無変更。
- undo/同期は既存の `align:flip` op の before/after 経路で自動的に正しく動く (after が新値を持つため、ピアにも `1-t` が伝播する)。
