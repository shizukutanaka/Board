# ADR-0065: コネクタ端点の再結合 / 解除

## 状態

採用 (v1.7.123)

## 背景

`endLineLike` は描画時に端点が図形上にドロップされれば `s.a`/`s.b` で結合するが、
**既存コネクタの結合をあとから変える経路がない**:

- 端点ハンドル (`p1`/`p2`) は未結合側にしか出ない (`if(!s.a)h.push(p1)`) —
  結合済み端点は掴めず、別図形への繋ぎ替えも解除も不可能。
- 未結合端点を図形上にドロップしても `sh.a` は更新されない
  (commit は `upd` op で座標のみ)。
- draw.io / Excalidraw では端点をドラッグして別図形へ再結合するのが
  標準操作 — 結合ミスや接続先変更のたびに引き直しが要る現状は不便。

## 決定

- 選択した line/arrow の p1/p2 ハンドルを**常時表示** (結合済みも掴める)。
- `applyResize` の p1/p2 分岐で掴んだ側の結合を即時解除 (`sh.a=null`) —
  ドラッグ中の端点は `connEnds` が生座標を返しプレビューがポインタに追従。
  同時に `_bindAt` でホバー先を `state.bindPreview` (render-only) に保持し、
  オーバーレイで破線ハイライト (draw.io の緑枠相当)。
- `pointerup` のコミット前に `_endPointBind(sh,handle)`:
  `_bindAt` が図形を返し、かつ自分自身・他端の結合先でなければ
  `sh.a|sh.b=hit`、それ以外は `null` (図形外ドロップ = 解除)。
- 変更は既存 `upd` op (before/after に a/b + 座標) — undo・同期・LWW は
  既存経路のまま。`elbow`/`start` と併用可。

## 断念した代替案

- **コンテキストメニューでの接続先選択**: 図形名を選ぶ方式は発見しにくく
  手間。直接ドラッグが標準。
- **結合済み端点は常に図形中心に吸着**: 端点位置を固定したいケース
  (図形内部に留めたい) もあるが、エッジ投影の一貫性を優先 — Board の
  結合は常にエッジ投影モデル。
- **`_bindAt` にポート位置 (辺選択) を追加**: 法線自動推定で十分
  (ADR-0062 と同じ判断)。

## 影響

- 既存コネクタの端点をドラッグして別図形へ再結合、空白へドロップで解除。
- 結合中の端点は再ドラッグしない限り従来どおり形状追従。
- 旧版 Board は `a`/`b` の新値をそのまま理解 (モデル不変)。
