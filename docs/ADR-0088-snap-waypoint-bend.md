# ADR-0088: ウェイポイント/エルボートランクのドラッグにもグリッドスナップ

## 状態

実装済み (v1.7.146)。

## 背景

`ptr.dragKind==='way'` (ADR-0076) と `'ebend'` (ADR-0072) のドラッグは
生のポインタ座標 (`wp`) をそのまま書き込み、全ての図形配置経路が通る
`snapPt`/`snapV` グリッドスナップを通らない。⇧G のスナップ設定に
従わない唯一の配置ジェスチャ。

## 決定

- way ドラッグ: 書き込みを `snapPt(wp)` に — ただし6pxクリア判定
  (中点への近接) は **生ポインタ**で評価する (グリッドに吸われて
  中点へ届かず削除できなくなるのを防ぐ)。
- ebend ドラッグ: trunk 座標を `snapV` 済みに (vert 判定は生座標で可)。

## 断念した代替案

- **オブジェクトスナップ (ガイド) も掛ける**: move/resize のガイドは
  bbox エッジ対象で、単一点にはエッジ索引が合わない。グリッドスナップの
  みに留める。

## 影響

- スナップ OFF 時は完全に同じ挙動。
