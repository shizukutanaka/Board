# ADR-0601: draw() の per-shape 隔離 — 1図形の例外が後続を殺さない

## 状態

実装済 (round310)。

## 背景

ADR-0565 は `draw()` の throw で rAF ループ自体が殺されるのを防いだが、
個別図形の描画例外は未隔離だった: `_drawIter` ループ中の1図形が `drawShape`
で throw すると、その図形以降の z 順全図形が描画されない — しかも同一図形が
毎フレーム再 throw するため**永続的な部分ブランク**となる。

現実的発生経路は薄い (validShape/validPatch が intake で構造検証済み) が、
過去バージョンの .board・将来の prop 追加・予期しない幾何エッジを踏んだとき
の影響が「盤面の大部分が消える」と致命的。

## 決定

`draw()` の両描画ループ (frame / 非 frame) と下書き `drawShape(_df())` を
`try{...}catch(_){}` で囲む。壊れた図形のみスキップし、残りは通常描画。

## 影響

- 最悪ケースが「盤面全体の一部が消える」→「壊れた1図形のみ非表示」に降格。
- オーバーレイ (選択枠/ガイド) は既に別レイヤのため影響外。
- パフォーマンス: try/catch は V8 でほぼゼロコスト (throw しない経路)。
