# ADR-0165: 非選択時の矢印キーでビューポートをパン

## 状態

実装済み (v1.7.223)。

## 背景

矢印キーは選択中のみ nudge (1px / ⇧10px) として機能し、非選択時は
完全な no-op だった — キーボードのみの利用者はキャンバスを動かす
手段が space ドラッグ相当の操作に限られた。Excalidraw は非選択時の
矢印でキャンバスをスクロールする。

## 決定

`state.selection.size===0` で矢印キーがビューポートをパン:
- ステップ 40px 相当 (⇧で 200px)、`state.viewport.zoom` で割って
  ワールド座標へ正規化 — ズームに関わらず画面基準で一貫した移動量。
- `preventDefault` でブラウザスクロールを抑止。
- 選択があれば従来の nudge を維持 (優先度は選択>nudge>pan)。

## 断念した代替案

- **常に pan + nudge 併用**: 選択があるのに画面も動くと nudge の
  精度感が崩れる — 排他的に。
- **ページ単位 (PageUp/Down)**: 矢印の微調整用途とは別物。

## 影響

- viewport のみ。シーン・履歴・共有には影響なし。
