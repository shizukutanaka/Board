# ADR-0199: 付箋をテキストに合わせる (fit-to-text)

## 状態

実装済み (v1.7.257)。

## 背景

長文を付箋に貼ると、付箋は固定サイズのままテキストがカード内で
クリップされて溢れた。draw.io の "Autosize" / Miro の "Fit to text"
相当がなく、手動リサイズで調整するしかなかった。

## 決定

`fitSticky` (ctx メニュー「テキストに合わせる」、sticky 選択時)。

- 幅: 折返しなしの最長論理行 + pad*2 へ **縮小のみ** (min 64)。
  横幅を現在値より広げないため、貼った段落が1行に伸びてカードが
  巨大化しない。
- 高さ: 新幅で折り返した行数 × lh + pad*2 (min 40)。
- 計測は `_fontStr(s,fs)`/`measureText` + `wrapTextCached` で
  実描画と同一のタイポグラフィ。一括 style op で undo/peer 両対応。

## 断念した代替案

- **幅を内容へ拡大**: 折返しを考慮しない1行幅で極端に横長になる。
- **テキスト量に応じた自動追尾**: 手動リサイズ意図と衝突するため
  明示操作のみ。

## 影響

- 空付箋は 64x40 に畳まれる。`s.text` 空なら変化なしで op 未発行。
