# ADR-0584: 反転時に結合点アンカー (aF/bF) を結合先のミラーに追従させる

## 状態

実装済 (round293)。ADR-0583 (labelPos のミラー) と同じクラスの残欠。

## 背景

`aF`/`bF` はコネクタ端点が結合先図形に張り付く位置を表す `{fx,fy}` — 結合先 bbox 内の比率座標 (0..1) で、描画時は `ba.x + ba.w·fx` の絶対位置に写像される (ADR-0209 系)。

`doFlip` で選択集合を反転すると、結合先図形 A 自身も鏡写しの位置へ移動する。そのとき `aF.fx` が未変換だと、新しい A 上で「A の左端から fx」の位置をとる — 反転前のアンカー点の鏡像位置ではなく、**視覚的に A の反対側の辺**へ端点がジャンプする。

## 決定

`doFlip` で、コネクタの結合先が**実際に反転された** (選択内かつ非ロック = `flipIds` に含まれる) 場合のみ、`aF`/`bF` を反転軸に沿ってミラーする:

- `axis==='h'` (x ミラー) → `fx = 1 - fx`
- `axis==='v'` (y ミラー) → `fy = 1 - fy`

結合先が反転されない場合 (未選択・ロック) は `aF`/`bF` を維持する — アンカーは動かない結合先上の同じ位置に留まるのが自然。

範囲外: 結合先は反転するがコネクタ自身は未選択のケースは、コネクタが flip op の before/after に含まれないため `aF` 変更を op に載せられず不変条件を壊す。データ整合性を優先して現状の挙動 (端点が結合先の新位置に追従) を維持する。

## 影響

- `flipShape` 内ではなく `doFlip` に実装 — 選択集合 (`flipIds`) の知識が必要なため。`flipShape` は純粋な形状ミラーのまま保持。
- before は反転前の clone、after は `aF`/`bF` ミラー後の clone で自己整合 — undo/ピア同期は既存 `align:flip` op 経路で正しい。
- テスト: 結合先と同時反転で `aF.fx` 0.2→0.8、結合先がロックされ反転されない場合は `aF` 維持を assert。
