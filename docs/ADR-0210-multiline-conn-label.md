# ADR-0210: コネクタラベルの複数行描画

## 状態

実装済み (v1.7.268)。

## 背景

インポート経路 (.excalidraw / .drawio) では `\n` 入りのラベルが
正規に到達するが、描画側は単一行前提 — `fillText` は改行を
無視して潰し、SVG は `<text>` 内に生の改行を吐いていた
(draw.io ラベルは複数行が一般的)。

## 決定

canvas と SVG の両方で `s.label` を `\n` 分割し、行高
`fs*1.25` で垂直中央にスタック: pill 矩形は全行を包含、
最長行で幅を決定、下線/取消線は行ごとに実測幅で描画
(canvas) / `<tspan dy>` スタック (SVG)。エディタは従来の
単一行 input のまま — ユーザー入力側の変更無し。

## 断念した代替案

- **エディタを textarea 化**: input→textarea はフォーカス/Tab
  巡回/ブラーcommit の挙動差を伴い変更面が大きい。描画側の
  堅牢化だけでインポート済みラベルの破損は解消するため後送り。

## 影響

- `label:'a\nb'` のコネクタが canvas/SVG で2行で正しく表示。
  単一行ラベルは lines.length=1 で従来と同一出力。
