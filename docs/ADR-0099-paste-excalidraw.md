# ADR-0099: クリップボードの .excalidraw JSON をペースト取り込み

## 状態

実装済み (v1.7.157)。

## 背景

Excalidraw で「コピー」したシーン/要素はクリップボードに JSON で
入るが、Board では SVG 判定→テキスト形状フォールバックとなり、
巨大な JSON 文字列のテキスト形状が貼られるだけだった。ADR-0098
でエクスポート経路ができたため、往路の対称性を揃える。

## 決定

- ペーストハンドラの SVG 判定の後、テキスト形状化の前に
  `{` 始まりかつ `"type":"excalidraw"` (先頭4KB内) を検出して
  `importExcText` へルーティング。
- `importExcText` が `false` を返した場合 (パース失敗/空シーン) は
  従来のテキスト形状化へフォールバック — 検出誤りでも情報を
  落とさない。

## 断念した代替案

- **.board JSON の同時取り込み**: .board はファイル拡張子経路が
  主で、クリップボード共有の需要が薄い — 同パターンで将来追加可能。

## 影響

- Excalidraw → Board のコピペ往路が1操作に。
- 非 excalidraw JSON は従来通りテキスト形状になる。
