# ADR-0121: 表示範囲を PNG 書き出し (ビューポートクロップ)

## 状態

実装済み (v1.7.178)。

## 背景

PNG/SVG 書き出しは常にコンテンツ bbox 全体 + padding — 巨大盤面の
一部だけを共有したい時はクロップできない。「今見えている範囲を
そのまま画像にしたい」はスクリーンショット相当の自然な要求。

## 決定

- `exportViewportPNG(scale)` — ワールド座標の表示矩形 =
  canvas CSS サイズ / zoom + 現在パン位置。`inView` で可視形状を
  抽出し、`_renderPngBlob` と同じ transform パターン (pad なし、
  view 左上を原点) で `drawShape` レンダリング。`exportScale`
  の上限は適用、既定 2x、非2x はファイル名 `board-view@4x.png`。
- export メニューに `ctxExportViewPNG` (PNG スケール項目の直下)。

## 断念した代替案

- **選択範囲クロップ**: 選択書き出し (ADR-0052) が既に bbox crop
  を提供 — 本機能は「ビューそのまま」(余白・部分切りを含む) で
  役割が違う。
- **`draw()` の画面キャプチャ**: 選択ハンドル・ガイド・プレビュー
  層が混ざる — シーンのみを再描画する方が正しい。

## 影響

- 部分形状は矩形エッジで切れる (canvas clip 相当の自然な結果)。
