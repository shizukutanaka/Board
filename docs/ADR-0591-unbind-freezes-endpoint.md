# ADR-0591: 結合解除で端点を解決済み位置へ凍結する

## 状態

実装済 (round300)。

## 背景

コネクタが結合中 (`s.a`/`s.b` + `s.aF`/`s.bF`) は `connEnds` が束縛先から端点を動的解決し、
格納の `x1`/`y1`/`x2`/`y2` は表示に使われない。その間に束縛先図形の移動や、コネクタ自体への
`gsnap`/`align`/`move` (束縛端まで平行移動する) で、格納座標は見た目のアンカー位置から
乖離し得る。

`unbindSelection` は `a`/`b`/`aF`/`bF` をクリアするだけで `x1..y2` を触らなかったため、
解除直後に端点が**乖離した格納座標へジャンプ**していた。

## 決定

`unbindSelection` でクリア前に `const e=_cE(s)` を呼び、解決済み端点を `x1..y2` へ凍結してから
`a`/`b`/`aF`/`bF` をクリアする — `computeConnClears` (結合先削除の凍結) と同じ規則。

## 影響

- 結合解除が視覚的に何も動かさない (端点がアンカー位置に留まる)。
- undo は `before` の束縛 prop + 旧格納座標を復元 — 一貫。
- テスト: 束縛先移動後の unbind で端点が解決位置 (>200) に凍結することを assert。
