# ADR-0092: 矩形の角丸/直角トグル

## 状態

実装済み (v1.7.150)。

## 背景

矩形は常時 `min(8, w/4, h/4)` の角丸で描画され、直角にする手段が
ない — 図表で直線的な sharp エッジが欲しい場面 (厳密な区画・罫線)
がある。Excalidraw の round/sharp 切替相当。

## 決定

- `s.r` (px、`undefined` = 既定の可変角丸 `min(8,w/4,h/4)`):
  ctx メニュー `ctxRrect` で `s.r` を 0↔(既定) に切替
  (`toggleRound` — style op で可逆、複数選択可)。
  - 現行 `s.r` が falsy なら `r=8` の固定角丸に (w/h の 1/4 を超えない
    よう clamp は描画側で継続); truthy なら `r=0` で直角。
- 描画は既存 `roundRect` ヘルパを `Math.min(s.r!=null?s.r:8,…)` に
  変更するだけ — 既定見た目は不変。SVG `<rect rx>` も同値。
- ヒット判定は bbox 据置 (角の欠け分は誤差内)。

## 断念した代替案

- **連続スライダー**: UI 面積を食う。二値で用途の大半をカバー。
- **既定を直角に変更**: 既存ボードの見た目を変えるので不可。

## 影響

- `s.r` は patch/undo で除去可能 (`??null` 経路)。
- ハッチ塗り・ラベル・ハンドル全経路で同じ半径が使われる。
