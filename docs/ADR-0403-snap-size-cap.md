# ADR-0403: snapshot 送信側サイズ上限 (>24MB は送信せず警告)

## 状態
実装済 (v1.7.439)

## 背景
ADR-0400 で送信側の 64KB チャンク化を実装した際、受信側の joined 上限 (24MB) を超える
スナップショットは全チャンクを送信した挙句、受信側で join 時に棄却される構造だった —
帯域と時間を浪費して結局届かない。

## 決定
`dc.onopen` の送信前に `_sm.length>24e6` で fail-fast し `snapBig` トーストを出す。
`24e6` は受信上限 25,165,824 (24MiB) より保守的な切り捨て閾値。`snapBig` i18n
(ja: ボードが大きすぎて共有できません / en: Board too large to share)。

## 影響
巨大ボードでも送信側で即座に原因が分かる。受信側ガードは二重防衛として存置。
