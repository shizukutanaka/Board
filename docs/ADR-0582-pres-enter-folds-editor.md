# ADR-0582: プレゼン開始時に編集 overlay を畳む

## 状態
実装済み (v1.7.609)

## 背景
`Presentation.enter()` はテキスト/ラベルエディタのオープン状態を考慮して
いなかった。編集中に ⇧P / ⌘Enter / プレゼンボタンで開始すると:

- textarea は z-index 9000 のプレゼン overlay の**下**に不可視で残存
- しかし DOM フォーカスは textarea に残ったまま — グローバル keydown の
  input ガードが `_pA()` より先に return するため、タイプした文字が
  不可視のままエディタへ流れる
- blur / 離脱時に `commitText` が走り、プレゼン中に図形が裏で変更される
  (ADR-0569/0572 と同型の「非到達化オーバーレイ」漏れ)

## 決定
`enter()` 冒頭で `_cxO()` — ローカルの明示的なプレゼン開始は overlay の
「畳みトリガ」として hideSelection (ADR-0569) と同格に扱う。
編集内容は `_cxO` の blur 経路で通常コミットされる (消失しない)。

## 影響
- プレゼン中の裏書き込み消失
- overlay 非到達化規則 (0559/0569/0572/0575) が全ライフサイクルで完結
