# ADR-0651: ページ複製 (duplicate page)

## 状況
ADR-0646 のページ操作は 追加/削除/改名/巡回 まで — draw.io のページタブが
持つ「複製」(テンプレート盤面の複写作業) が無かった。コピー→新ページ→
ペーストの手順でも可能だが、ページを跨ぐ操作として3手要する。

## 決定
pgBar に ⧉ ボタン (`pgDup`) を追加し `_pgDup` を実装。ADR-0650 で
`pageAdd` が `shapes` を持てるようになったため、**1つの原子 op でページ +
メンバー複製**が完結する (undo もページ単位)。

- 複製対象は `(s.pg||pages[0].id)===src.id` の位置規則で収集 — 未スタンプ
  図形も先頭ページ帰属として正しく複製される。
- リマップは `_placeCopies` と同一の規則: `idMap` で図形 id を再発行し、
  コネクタ `a`/`b` が複製内の図形を指す場合のみ新 id へ置換
  (ページ外を指す束縛は保持)、`groupId` も新 id に写像。
- ページ名は `<元名> 複製` (i18n `ctxDuplicate` 流用)。
- `Net.broadcast(addMany)` の同伴送出 — ADR-0650 と同じ互換層
  (pre-0650 ピアも図形を受け取る)。
- `!_pgOn()` の単一ページ盤面では先に pages[0] を実体化してから複製
  (`_pgAdd` と同じ二段コミット)。
- 完成後は `switchPage` で複製ページへ着地。

## 非目標
ページ間のドラッグ並べ替え、複製時の座標オフセット (忠実な同位置複製
がページ複製の意味)、選択部分のみの部分複製。
