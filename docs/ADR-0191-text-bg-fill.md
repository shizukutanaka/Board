# ADR-0191: テキストの背景塗り (s.fill)

## 状態

実装済み (v1.7.249)。

## 背景

`「設定可能だが描画されない」監査` の残件 — テキスト選択中に
fill スウォッチ/スタイルコピーで `s.fill` を設定できても、
描画経路が `s.fill` を読まなかった。draw.io ではテキスト背景色
として使われる。

## 決定

`s.fill` 設定時、テキスト行の最大幅 `mw` を測定して3pxパッドの
ハイライトプレートを本文背面に描画 (align 各モードで位置一致)。
canvas と SVG export の両方。h=行数×lh、sticky は対象外
(自身が色付きノート)。

## 断念した代替案

- **行ごとのプレート**: 各行で幅が違うと継ぎ目が目立つ — 全体
  1枚の矩形が読みやすい。
- **fill ガイドの排除**: fill をテキストで無効化する方が矛盾を
  残す — 描画する方が直感通り。

## 影響

- `s.fill` 未設定のテキストは不変。`mw` 測定は fill 設定時のみ
  (未設定テキストの per-frame コストは変わらない)。
