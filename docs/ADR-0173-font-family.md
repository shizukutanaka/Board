# ADR-0173: 書体ファミリ巡回

## 状態

実装済み (v1.7.231)。

## 背景

Board の文字は常にシステムフォント固定 — Excalidraw は手書き風/
通常/等幅の3書体切替を持つ。メモやコード片を等幅で書きたい需要は
定番。Webフォントはオフライン信条と外部リソース禁止に反するため
選択肢はシステムスタックに限定される。

## 決定

- `s.font` ∈ `{undefined|'mono'|'serif'}`。ctx「書体」で
  system→mono→serif→system を巡回 (text/sticky/ラベル保持図形、
  ロック除く)。style op で undo/同期適合。
- `_fontFam(s)` が両描画経路の唯一の family 決定点 — `_fontStr`
  (canvas) と全 SVG text 要素が `_fontFam(s)` を参照。スタックは
  オフライン安全なもののみ (`ui-monospace…` / `Georgia,…`)。
- `_wrapCache` キーに `s.font` を追加 — 書体でメトリクスが変わるため。
- `positionTextEditor` が `fontFamily` を反映 — 編集中も描画と同じ
  書体。`_styleOf` が `font` を運ぶためスタイルコピーでも伝播。

## 断念した代替案

- **フォント選択モーダル/ドロップダウン**: 3択に対して巡回項目で十分
  (他の ctx 巡回項目と一貫)。
- **Google Fonts 等の Web フォント**: 外部リソース禁止・オフライン
  要件に違反。

## 影響

- 未設定形状は従来スタックで見た目不変。エクスポート SVG は参照
  スタック名で埋め込まれるため閲覧環境のフォント有無で微妙に
  変わり得る — 代替フォールバック付きスタックで影響は軽微。
