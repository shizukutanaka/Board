# ADR-0127: マーキー選択はロック形状を除外

## 状態

実装済み (v1.7.184)。

## 背景

マーキーはロック形状も選択に含めていた — 編集系の操作は結局
`!s.locked` で除外するので選択がノイズになるだけ。Figma/draw.io
もロック要素はマーキーに乗らない。

## 決定

- `endSelect` のマーキー確定ループに `!s.locked` 条件を追加
  (包含・交差どちらのモードでも)。
- シングルクリックの選択はそのまま — ctx「ロック解除」への到達
  経路を残す (加えて ADR-0123 の「全てロック解除」もある)。

## 断念した代替案

- **クリック選択もロック拒否**: 解除の入口が消えるため不可。
- **ロック形状のマーキー範囲ハイライト**: 情報量の割に実装が
  重い — 選択に乗らないだけで十分。

## 影響

- 全てロックされた領域のマーキーは空選択になる (意図通り)。
