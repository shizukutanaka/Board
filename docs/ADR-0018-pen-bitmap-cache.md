# ADR-0018 — ペンストロークのビットマップキャッシュ

- Status: Accepted
- Date: 2026-09-23
- 関連: ADR-0016 (draw() 空間索引) — 「走査コスト」を解消した次の段として「描画コスト」を解消

## 問題

`drawPen` は可変幅インクのため**毎フレーム**以下を実行する:
- `penWidths()` — 2 配列確保 + 全点 `Math.hypot` (O(n))
- n-1 回の `beginPath/moveTo/quadraticCurveTo/stroke` (O(n) の raster 呼出)

120 点のストロークが 300 本可視なら ~36,000 stroke/フレーム。実測
(pen 4000 本 + rect 1000 の盤面、全可視ズームで draw() のみ計測):
**p50 175ms / フレーム** — 60fps 予算 (16.7ms) の 10 倍。pan/zoom 中はもちろん、
アイドル後の 1 フレームでも同額かかる。

コミット済みストロークは op 間で不変 — 典型的なホワイトボード手法
(Excalidraw/Konva の shape-level rasterization)に倣い、オフスクリーン
キャンバスに 1 回ラスタライズし `drawImage` で使い回す。

## 決定

`_penCache`(id → エントリ、LRU、ピクセル総量 12M px ≈ 48MB 上限):
- ビットマップは **bbox 原点相対**( `translate(-bx,-by)` で描画)かつ
  **zoom 連動解像度** R = clamp(zoom*DPR, 0.25, 2)。移動してもピクセル内容は
  不変なので `drawImage(cv, bx, by, bw, bh)` だけで再配置できる。連続ズーム中は
  1.5× バケット単位でのみ再レンダー (ジェスチャー中 ~log(Δzoom)/log(1.5) 回)。
  ※固定 R=2 の初版は巨大ストローク密集盤面でピクセル予算を即座に使い切り
    125 エントリしか残らなかったため適応化した。
- 有効性シグネチャ (O(1)): `pts` 配列参照 + 長さ + 先頭/中央/末尾点の絶対座標 +
  stroke + size。bbox を再計算しない — シグネチャ一致 ⇒ 位置も不変 ⇒ 保存済み
  bx/by がそのまま使える。
- in-place 変異は `Shape.translate`(均一)と `flipShape`(鏡像)のみで、
  いずれも p0/pN の絶対座標を動かす ⇒ シグネチャが検知。その他の op は
  `pts` を丸ごと差し替える ⇒ 参照比較が検知。
- **ミス時はそのフレームはベクトル描画**にフォールバックし、シグネチャを更新。
  ドラッグ中は毎フレーム sig が変わるため再ラスタライズせず( churn 回避)、
  ドラッグ終了後の静止フレームで 1 度だけ再描画される。
- ビットマップ経路はメインキャンバス (`c===ctx`) のみ。エクスポート
  (PNG/SVG/PDF の `oc`) とミニマップは従来のベクトル経路 — 出力忠実性を維持。
- `state.draft` (描画中ストローク) は常にベクトル。
- `zoom*dpr > 4` ではベクトル(高倍率で少数しか可視でないため + ボケ防止)。
- ラスタライズ寸法 > 4096px または単体で 12M px 超の巨大ストロークもベクトルに
  フォールバック。

## 却下した案

- **Path2D キャッシュ**: 可変幅はセグメント毎に lineWidth が必要で単一 Path に
  焼けない。等幅近似は筆跡の質を落とす。
- **dirty-rect (FT-13)**: draw() の部分再描画は drawGrid/選択/オーバーレイまで
  含む設計変更で L 級・高リスク(チケットも「慎重に」)。形状レベルキャッシュは
  独立に着地でき、ペン以外の型は既に安価(矩形 ≈ 数呼出)。
- **幅配列 `w` のみキャッシュ**: penWidths 計算は省けるが raster 呼出 (stroke × n)
  が残り、支配コストが残る。

## 検証 (実施済)

- `node test.mjs` 全緑: miss → settle → hit のライフサイクル、translate /
  flip / stroke / pts 置換の全無効化経路、export・高倍率・draft のベクトル
  フォールバックを behavioural assert で固定
- 実ブラウザ A/B (headless Chrome、pen 4000 + rect 1000、全可視ズーム、
  draw() のみ 25 フレーム): **p50 175.3ms → 15.2ms (11.5×)**, p95 202 → 21ms。
  キャッシュ 3650 エントリ / 5.8M px で予算内に収束
- スクリーンショット差分 (zoom 0.8、1024×768): 差分画素 **66/737,280 = 0.009%**、
  すべてストローク縁の AA リサンプル — 実質的にピクセル同一
