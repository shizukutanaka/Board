# ADR-0140: 選択2図形のコネクタ接続

## 状態

実装済み (v1.7.197)。

## 背景

既に置いてある2図形を結ぶには、矢印ツールで端点を2度精密に
結合させる必要があった。draw.io の「接続」/ Miro の
quick-link は選択済みペアから一発生成する。

## 決定

- `connectSelection()` — 選択が「未ロック・可視・コネクタ以外の
  図形ちょうど2個」の時のみ動作。中心→中心の矢印を
  `a:`/`b:` で両端バインド (connEnds がエッジ投影して追従)。
- ctx メニュー「2図形をコネクタで接続」は上記条件でのみ表示。
- 1つの `add` op → undo は一発、ワイヤー同期は既存経路。

## 断念した代替案

- **ツールバー常設ボタン**: 使用頻度に対してパレット面積が高い。
- **line ではなく arrow 生成**: フロー図用途が主なので矢印
  (ctx で直線変換・両端ヘッド等は既存機能)。

## 影響

- 付箋/テキスト/画像/フレーム間でも接続可 — エッジ投影は
  `G.bbox` 経由なので全 bbox 図形が正しく動く。
