# ADR-0586: 結合先図形の回転で aF/bF を extent へ再正規化する

## 状態

実装済 (round295)。ADR-0583/0584/0585 (反転・方向転換の経路プロパティ変換) 系の網羅の最終ピース。

## 背景

`aF`/`bF` はコネクタ端点が結合先図形に張り付くアンカーで、結合先の**回転込み extent** (`_bb` が返す軸平行包絡) 上の比率座標 `{fx,fy}` として保持される。

`doRotate` で結合先を回転すると extent の向きが変わるため、同じ `(fx,fy)` は全く別の辺を指す — 「左辺の中点」にピンした端点が 90° 回転後に同じ分数のまま別の辺へ滑る。draw.io の固定アンカー (exitX/exitY) はセルのローカルフレームに張り付き、セルと一緒に回転するのが正しいセマンティクス。

## 決定

`doRotate` で回転された図形を結合先に持つ全コネクタ (`sel` 内外問わず) を対象に、アンカー点を図形と同じ変換で回転し、新 extent の比率へ再正規化する:

1. 回転前の extent マップ `extB` を保存。
2. アンカー世界座標 `p₀ = (ob.x+ob.w·fx, ob.y+ob.h·fy)`。
3. 図形の変換は「中心 c₀ を群中心 g まわりに軌道移動 → 新中心 c₁ まわりに自転」なので、アンカーも `p₁ = c₁ + R_d(p₀ − c₀)` と写像する (軌道と自転を二重適用すると過回転になることに注意 — 初版はそのバグを自分で踏んだ)。
4. 新 extent `nb` で `f.fx = (p₁.x−nb.x)/nb.w` などへ正規化し `_c01` でクランプ。

`sel` 外のコネクタは op の before/after にも含めないと undo/ピア同期が壊れるため、非選択コネクタは before/after へ push する (選択内コネクタは `sel.map(clone)` で既にカバーされるので重複追加しない)。

## 影響

- 結合先のみ回転・コネクタ未選択のケースでも端点がピン位置を保持する。結合先が未回転 (未選択/ロック) なら `aF`/`bF` は不変。
- before/after にコネクタ分を同梱 → undo は旧 `aF`/`bF` を正確に復元、ピアへも同一パッチが伝播。
- テスト: 左辺中点アンカーの結合先を 90° 回転 → `aF` が `{0.5, 0}` (上辺中点) へリマップされることを assert。
- 任意角の回転でもワールド座標で正確に写像するため、90° 倍数以外でもアンカー位置が数学的に正しい。
