# ADR-0554: プレゼンの `_frames` を遷移毎に存在フィルタ

## 状態
実装済 (v1.7.582)

## 背景
`Presentation.enter()` は `_frames = _getFrames()` でスナップショットを取る。プレゼン中に
リモートピア (または将来のローカル経路) がフレームを削除すると、`_frames` は削除済み
オブジェクトへの stale 参照を抱えたまま — `_zoomToFrame` は古い座標へズームし、カウンタは
存在しないフレームを数え続ける。全フレーム消失時も overlay が残り操作不能になる。

## 決定
`_goto(i)` の先頭で `_frames = _frames.filter(f => byId(f.id))` — 削除済みを毎遷移で
drop。`!_ln(_frames)` なら `leave()` でクリーンに終了。`byId` は O(1)、遷移頻度は
人間操作レベルなのでコストは無視できる。

## 影響
- リモート削除でプレゼンが stale 座標へズームする経路を閉塞
- 全フレーム消失時に黒 overlay + Esc のみのデッド状態を解消
- live 参照のためリモート `upd` (移動/リサイズ) には従来通り追従
