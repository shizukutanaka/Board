# ADR-0129: ⇧click で選択済み図形を解除

## 状態

実装済み (v1.7.186)。

## 背景

⇧click は「追加」だけだった — 既に選択済みの図形を ⇧click しても
何も起きず (move ドラッグが始まる)。Figma/draw.io/Excalidraw の
トグル選択 (選択済み→解除) が欠けていた。

## 決定

- `pickOrMarquee` で `alreadySel&&e.shiftKey` → `toSelect` 全員を
  `selection.delete` — グループはまとめて外れる。
- 解除後は `return` (move ドラッグを始めない)。

## 断念した代替案

- **一部分選択グループのトグル**: 部分的に選ばれたグループの
  ⇧click は既存の「残りを追加」にフォールする自然な拡張として
  そのまま。

## 影響

- ⇧click が解除になるだけ — ドラッグ移動 (⇧なし) や ⇧+ドラッグの
  加算マーキーは不変。
