# ADR-0103: カーソル位置に貼り付け (ctx メニュー)

## 状態

実装済み (v1.7.161)。

## 背景

`doPaste` はビューポート中央へカスケード付きで貼る — 右クリック
した場所へ置きたい「ここに貼り付け」が無い (draw.io / PowerPoint
に存在)。

## 決定

- `openCtxMenu` が開いたワールド座標を `m._wx/_wy` に記録
  (`G.s2w(client−rect)`)。
- `doPasteAt(wx,wy)` — クリップボード bbox 中心をその点へ
  `_placeCopies` で平行移動。**カスケード無し** — ユーザが場所を
  指定したため `_pasteCount` を触らない。

## 断念した代替案

- **カスケード維持**: 位置指定意図と矛盾 — 毎回同じ点へ確定的に
  貼る方が正しい。

## 影響

- ⌘V (viewport 中央) と ctx「ここに貼り付け」(指定点) の2経路が
  共存、undo は共通の addMany op。
