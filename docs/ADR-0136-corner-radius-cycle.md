# ADR-0136: 矩形の角丸サイクル (ctx)

## 状態

実装済み (v1.7.193)。

## 背景

`s.r` は描画経路全域 (canvas roundRect / SVG rx / ハッチ) で実装済み
だが変更手段が無く、既定 8 固定だった。Figma/draw.io では角丸は
編集可能。

## 決定

- `cycleCorner()` — 選択中の未ロック矩形の `s.r` を
  0→8→16→24→0 に巡回。style op として記録されるため
  undo・ワイヤー同期・wclock 衝突解決は全て既存機構に委譲。
- ctx メニュー「角丸を切替」は選択に未ロックの rect を含む時のみ表示。

## 断念した代替案

- **スタイルパネルにスライダー追加**: 入力 widget が増えて
  狭い panel が混雑 — ctx 巡回で十分 (dash/arrowhead と同じ
  パターン)。
- **角ドラッグハンドル** (Figma 式): ハンドルヒット判定の改修が
  大きく、touch の誤タップリスクがある。

## 影響

- `s.r` はフィル時に `min(r,w/4,h/4)` で既にクランプ済みのため
  小さい矩形でも安全。
