# ADR-0131: 90°回転 (ctx + ⇧R)

## 状態

実装済み (v1.7.188)。

## 背景

回転は `,`/`.` の ±15° ステップのみ — draw.io の「Rotate 90°」のような
直行配置の基本操作に6回のキー入力が要る。

## 決定

- ctx「90°回転」(`⇧R`) — `doRotate(90)` を呼ぶだけで、回転の全経路
  (ボックス/点ジオメトリ/複数選択 pivot) がそのまま効く。
- `⇧R` は `KEYMAP` の素通しより前に分岐 — 'r' はツールキーなので、
  選択がある時だけ横取りする (空選択なら従来通り rect ツール)。

## 断念した代替案

- **⇧R = -90° (逆回転) との対**: 現状は +90° のみ — 15°刻みキーが
  既に双方向なので単方向で十分。

## 影響

- なし — `doRotate` は既存の align op 経路で undo/同期済み。
