# ADR-0709 — 編集中図形の off-page 化で overlay を畳む

## 状態
採用 (v1.7.735)

## 文脈
`_teFollow`/`_lblFollow` は編集対象の `!s||_hd(s)||_lk(s)` で overlay を畳む
(0559/0569/0572 — 削除/非表示/ロック)。だが remote `upd{pg}` で対象が別ページへ
再帰属された場合は畳まれず、overlay が不可視の図形へ入力を送り続け得た
(タイプした内容は見えない図形へ沈黙適用)。

## 変更
- 両フォロワーの畳み条件へ `!_pgOk(s)` を追加 — 閲覧ページ外の編集対象は
  畳む (del/hide/lock と同じ到達不能規則のページ版)
