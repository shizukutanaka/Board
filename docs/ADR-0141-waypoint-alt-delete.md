# ADR-0141: Alt+click でウェイポイント削除

## 状態

実装済み (v1.7.198)。

## 背景

ADR-0076/0090 で追加した中間頂点 (way) は、ドラッグで移動・中点
で追加はできるが個別削除ができず、消すには ctx のルート
リセット (全クリア) しかなかった。Figma は ⌥+クリックで頂点を
削除する。

## 決定

- 単一選択の直線/矢印の既存ウェイポイントに対する Alt+pointerdown
  を「ドラッグ開始」ではなく削除とする。
- `wa.splice(i-1,1)` 後、空なら `way=null` (レガシー単一点形式
  との正規化は `_wayArr` 側で吸収済み)。
- style op として記録 → undo 一発・ワイヤー同期は既存経路。

## 断念した代替案

- **dblclick 削除** (draw.io 式): コネクタの dblclick はラベル
  編集に割当済み — 衝突するため Alt+click (Figma 式) を採用。
- **右クリックメニュー項目**: 頂点単位のメニューは hit 状態を
  ctx に運ぶ必要があり複雑。

## 影響

- Alt は既にスナップ抑制 (ADR-0128) の修飾キー — 頂点の上では
  削除が優先 (ドラッグが始まらないので競合なし)。
