# ADR-0600: 束縛コネクタ×ダメージ矩形の不変条件を文書化

## 状態

実装済 (round309、docs)。コード変更は ADR-0597/0598/0599。

## 背景

ADR-0597→0599 で 3 連続の同型修正が必要だった (5 サイト: doMove/gresize/grot/
resize/rotate + `_apply`) — 束縛コネクタの掃引領域がダメージ矩形から漏れる
実害クラスとしてパターン化したため、ルールを明文化する。

## 決定

不変条件: **ダメージ矩形を構成する全経路は、束縛先が変形するコネクタの掃引領域を
含める**。`aF`/`bF` 端点は束縛先 extent から動的解決されるため、束縛先の変形で
コネクタ path は対象図形の bbox を越えて変化し得る。収集判定は
`(aF && a∈対象) || (bF && b∈対象)`、union は `_dmgPair(before_bb, after_bb, size余白)`。

- architecture.md のダメージ矩形節に追記
- spec.md のコネクタ束縛項に不変条件として追記

## 影響

- 将来の新規ダメージ経路 (新ジェスチャ等) が従うべき規則が文書上の不変条件に。
- 非対象: ebend/cbend/way/lblpos はコネクタ自身を編集 (自身の bbox or `_iv()`)。
