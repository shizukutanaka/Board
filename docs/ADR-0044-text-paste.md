# ADR-0044: テキストのペースト

## 状態
実装済み (v1.7.102)

## 背景
OS クリップボードの `paste` ハンドラは画像 (`image/*`) と ADR-0042 の SVG
markup しか処理しておらず、**プレーンテキストのペーストは何も起きない**
ギャップがあった (Board 内部の shape コピーは `state.clipboard` 経由で別系統)。
エディタ・ブラウザ・チャットからのコピーを板に置くのは定番ワークフローで、
spec.md §14.2 P2「入出力の幅」の残存項 (Markdown 貼付) の現実的な着地点
でもある — Board の text shape はリッチテキストを持たないので、Markdown は
マークアップのまま平文として置くのが正しい粒度。

## 決定
- `text/plain` クリップボードを viewport 中央に `text` shape として貼付。
  検出は「トリム後非空」だけ — URL・コード・箇条書き等も全てそのまま置く。
- 優先順位は `image/*` > `<svg` markup (ADR-0042) > `text/plain` — 画像を
  含むコピーは従来どおり画像が勝つ。
- サイズ: `w = min(600, 最長行×fs×0.55)`、`h = 行数×fs×1.4`、fs=16。
  `PASTE_MAX_CHARS=4000` で切り詰め (巨大なクリップボードダンプで盤面を
  埋めない — ADR-0039/0042/0043 と同じ天井の発想)。
- `add` 単一 op (undo 一発)、貼った shape を選択、toast `textPasted`。
- input/textarea 内のペーストは従来どおり素通し (早期 return)。

## 断念した代替案
- **Markdown 構文の解釈** (見出し→大きい文字、箇条書き→箇条書き図形) →
  Board の text shape は単一 fontSize でリッチ表現の受け皿がない。
  見た目より構造を崩さない方が良い (平文のまま置く)。
- **sticky shape への貼付** → sticky は色付き背景+中央寄せの「付箋」で、
  長文・複数行のコピーには向かない (text shape の方が自然)。
- **行ごとの shape 分割** → 1文1shape は編集単位が細かすぎて邪魔。
  複数行のまま1 shape が妥当 (text shape は `\n` を保持できる)。
- **URL のみリンク化** → Board にリンク概念がない。テキストとして置く。

## 影響
- エディタ/ブラウザ/チャットからのテキストコピーが板に置けるようになる。
- `<svg` markup は引き続き SVG インポートに流れる (誤爆なし)。
- Markdown の `#`/`*` 等はそのまま平文として残る — spec の「Markdown 貼付」
  は構文解釈ではなく「取り込める」ことと解釈した (ADR に明記)。
