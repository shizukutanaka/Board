# ADR-0531: spec.md ロードマップの現況同期

## 状態

実装済み

## 背景

spec.md §14.3 のロードマップ表と§14.2「課題」節が実装状況から遅れていた:
DOM ミラー a11y (P1) とインポート拡張 (P2) とコードパス・パリティ監査 (P2) が
未完扱いだったが、ADR-0041/0042-44/0199 等ですでに実装済み。画像肥大も
「段階1 解消・段階2 残り」のままだったが、ADR-0069 のワイヤ `img` 参照と
ADR-0379 のチャンク送信で段階2 も完了している。誤ったロードマップは
重複実装や誤優先度付けを招く。

## 決定

ロードマップ表の全完了項目を `~~打線~~` + DONE に変更し、画像肥大と
テスト偏りの「課題」節も実状に更新。新設 §14.3.1 に現行の真の残課題を
集約 (多ページのみ未完、z/frac は決定済み恒久併存、ポインタ系列検証は
harness 制約の明示)。

## 影響

- index.html へのバイト変化なし (docs のみ)
- ロードマップの唯一の未完項目が多ページに確定
