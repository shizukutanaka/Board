# ADR-0564: spec.md §8 へ wire 収束保証の同期

## 状態
実装済 (v1.7.592)

## 背景
spec.md §8「同期プロトコル」は op エンベロープ・LWW・共有リンクまでしか
言及していなかった。最近の wire 層の収束保証 — incarnation 付き peerId
(ADR-0459: リロードで seq が 0 に戻っても dedup キーが衝突しない)、
wclock の IDB 永続化 (ADR-0460: LWW 仲裁履歴がリロードを跨ぐ)、
再組立の seq0 再起動 (ADR-0563) — が仕様書レベルで読めなかった。

## 決定
§8 に2行を追記: 「ピア識別」と「チャンク再組立」の不変条件として記述。

## 影響
将来の wire 変更者が収束の前提 (peerId の一意性・wclock の永続性・再組立の
冪等性) を仕様書で確認できる。コード変更なし。
