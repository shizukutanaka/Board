# ADR-0137: 図形の非表示 / すべて表示

## 状態

実装済み (v1.7.194)。

## 背景

作業中の一時的な「隠す」手段が無い — Figma の eye / ⌘⇧H に相当。
スクラッチパッドでも「雑多な下書きを一時的に退ける」需要はある。

## 決定

- `s.visible===0` を非表示マーカーとする (既定は undefined = 表示、
  JSON 直列化・ワイヤーペイロード両対応)。
- `drawShape` 冒頭で early return — ミニマップ・PNG/SVG エクス
  ポート・ペンキャッシュ等の全描画経路が自動的に追従。
- `pickTop` 4経路 + マーキー + ⌘A + 同種/同色選択 + ctx 全選択が
  `s.visible!==0` でフィルタ — 非表示図形は完全に操作不能
  (消しゴムも pickTop 経由なので自然に除外)。
- `hideSelection()` は style op `{id,visible:0}` として記録し、
  隠した図形を選択から外す (再選択不能になるため)。
- `showAllShapes()` は全 `visible===0` を一括解除 — 非表示図形は
  個別再選択できないため「すべて表示」のみ (Figma と同じ判断)。
- キー: ⌘⇧H。ctx: 「非表示」(選択時) /「すべて表示」(非表示が
  ある時のみ)。

## 断念した代替案

- **レイヤーパネルでの個別 eye トグル**: パネル新設は
  scratchpad の「単一画面」設計と衝突 — ctx の一括解除で十分。
- **`hidden` prop 名**: `visible` は export/外部ツール連携で
  意味が通じるため採用。

## 影響

- 結合コネクタは隠れない — 非表示は選択した図形のみ。端点が
  見えない図形を指すコネクタは宙に浮くが、図形本体の削除では
  ないため connClears は走らない (意図どおり)。
