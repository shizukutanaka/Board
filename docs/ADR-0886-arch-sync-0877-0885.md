# ADR-0886 — Sync architecture.md to the ADR-0877–0885 cluster

## Status
Accepted, v1.7.912 (docs-only)

## Context
architecture.md was last synced at ADR-0876. Nine ADRs landed since —
image-ingest guards (0877/0878), toast stack cap (0879/0880), host-API
error-path audit (0881), SR style-identity announce (0882), i18n label
surface audit (0883), IDB open lifecycle fix + pins (0884/0885) — none
reflected in the document future readers actually consult.

## Decision
Sync, in place, without restructuring:

- **§6 Persist** gains an "open lifecycle" paragraph: `onblocked` →
  in-memory + toast, `onversionchange` → yield; tx error surface
  (`txDone` complete/error/abort, `reqDone` error→reject — abort does
  NOT fire `onerror`, so both are required); 0885's behavioural pins.
- **Import bullets** gain the image-ingest line: `_imgImportFile`'s
  pre-read 32MB `_bigFile` guard (0877 — FileReader-ing a huge file is
  itself the memory spike), the 0×0 degenerate rejection (0878), and the
  surrounding 16MB/2048px bounds for context.
- **Accessibility bullets** gain: `describeShape` announces
  dash/align/valign/text-flags (0882) and the 4-toast cap (0879/0880).
- **i18n** gains the 0883 audit-complete note (callsite coverage pinned,
  four data-t mechanisms, dynamic labels via `t()`).

No code changes; behaviour unchanged.
