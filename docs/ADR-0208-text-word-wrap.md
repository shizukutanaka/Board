# ADR-0208: テキストの幅折返し (word wrap)

## 状態

実装済み (v1.7.266)。

## 背景

Board のテキスト図形は `s.w` を揃えアンカー/リサイズ寸法として
持つが、描画は改行のみで分割 — 長文は幅を無視してはみ出した。
draw.io の wordWrap=1 相当が無かった。

## 決定

`s.wrap` フラグ (既定 off): ON で既存 `wrapTextCached`/`wrapText`
(禁則処理込み、付箋と同一実装) を `|s.w|` 幅で適用 — canvas
(measureText 実測) と SVG (文字数推定) の両方で同一行を生成。
ctx「テキスト折返し」で style op トグル。既定 off なので既存
ボードは不変。

## 断念した代替案

- **常時 wrap**: リサイズで既存テキストの行がリフローする破壊的
  変更になるため opt-in。

## 影響

- `s.wrap` セット時、リサイズ (`s.w` 変更) で行が自動リフロー。
  `s.align`/`s.fill` ハイライト/下線・取消線は wrap 後の行に
  そのまま適用される。
