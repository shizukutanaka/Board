# ADR-0217: ルートリセットの ctx 到達性補完

## 状態

実装済み (v1.7.275)。

## 背景

「ルートをリセット」は way/bend/elbow/curve が設定された
コネクタにのみ ctx メニューで到達できたが、`labelPos`
(ラベル位置) や `cbend` (曲線ベンド) **だけ**が残った
コネクタではゲートが偽になり、⌥click 以外に戻す手段が
無かった。resetRoute 本体は両値を既に消去するので
到達性だけの問題だった。

## 決定

ctx 行ゲートと内部 continue に `labelPos!=null` /
`cbend!=null` を追加。⌥click リセット文法
(ADR-0144/0145) のタッチ・キーボード到達性が完結した。

## 断念した代替案

- 別行「ラベル位置をリセット」: 1 op で全部戻る既存の
  resetRoute と重複し、メニューが膨らむだけ。

## 影響

- ctx メニューのゲート条件のみ。保存形式・undo 不変。
