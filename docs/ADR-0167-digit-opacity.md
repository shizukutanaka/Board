# ADR-0167: 数字キーで不透明度を設定

## 状態

実装済み (v1.7.225)。

## 背景

不透明度の変更はスタイルパネルのスライダ操作のみ — マウスを離す
必要があり微調整が遅い。Figma はベア数字キーで選択オブジェクトの
不透明度を直接設定する (`5`→50%、`0`→100%)。

## 決定

- `0-9` のベア数字キー (meta/shift なし、選択時のみ) で
  `applyStyleToSelection({opacity: n/10})`、`0` は `1` (100%)。
- 既存の style op 経路に乗るため undo 1回・リモート同期・LWW・
  付箋マッピング全て自動適合。
- テキスト編集/モーダル/プレゼン中は既存ゲート (`input,textarea`
  ターゲット除外・`_openDialog`・Presentation early-return) で
  到達しない。

## 断念した代替案

- **ダブルタップ `55`→55%**: Figma は対応するが、単一桁で十分
  (スライダがある微調整の補助)。バッファリングの複雑さを見送り。
- **`⌘数字` 修飾子**: ⌘1-9 はブラウザのタブ切替と衝突。

## 影響

- 数字キーは従来 KEYMAP 外 (dead key) だったため競合なし。
