# ADR-0106: 起動時の空ビュー → 自動フィット

## 状態

実装済み (v1.7.164)。

## 背景

viewport は永続化されるため、「コンテンツから遠くへ pan した
状態で終了→再起動」だと真っ白なボードが出て**データ消失と
誤認する**。scratchpad では致命的な第一印象。

## 決定

- `_fitIfEmptyView()` — `main()` のロード完了後 (Persist + hash
  import の後) に一度だけ実行。形状が存在するのに union bbox と
  ビューポート矩形が全く交差しなければ `fitToContent()`。
- ビュー内に1つでも形状が見えていれば不発 — 意図的な空ビューは
  尊重する (永続ビューの正確な復元が原則)。

## 断念した代替案

- **毎回 fitToContent**: 永続ビューの復元意図を壊す。
- **トーストで「コンテンツはこちら」だけ通知**: 空白のままだと
  状況は改善しない。

## 影響

- 空ボード (shapes=0) では早期 return。
- Share hash import 後にも適用 — 共有リンクが古いビュー指定を
  持っていてもコンテンツへ案内される。
