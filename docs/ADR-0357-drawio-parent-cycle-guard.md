# ADR-0357: drawio import `off()` の parent cycle 無限再帰ガード

## 状態
承認 — round84

## 背景
`off(id)` は parent チェーンを再帰的に辿って世界座標オフセットを
解決する。`a.parent=b, b.parent=a` のような循環を持つ drawio
ファイル (手編集・他ツール出力) で、メモ化前に無限再帰して
スタックオーバーフロー = import クラッシュになる実脆弱性が
あった。

## 決定
再帰前に `_off.set(id,{x:0,y:0})` の暫定値を先行登録 — 循環の
2周目は暫定値で打ち止めになり、循環部は 0 オフセットとして
収束。正常ファイルでは挙動不変。

## 影響
+~120B。drawio import の堅牢性向上。2044 全緑。
