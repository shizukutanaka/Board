# ADR-0213: ctx メニューからのアンカー固定

## 状態

実装済み (v1.7.271)。

## 背景

ADR-0209 の固定アンカーは ⌥+ドロップのジェスチャ限定 —
タッチ/キーボードユーザーには到達不能 (ADR-0135 と同じ
修飾キー依存の死角)。ctx メニュー経路が必要だった。

## 決定

ctx「アンカー固定/解除」(`pinAnchor`): 結合済みコネクタの
各端点について、現在のフローティング接触点を分数アンカー
として記録 (固定)、再実行で解除 (フローティングに戻る)。
接触点は既にエッジ上にあるため生の分数をそのまま保存 —
固定しても見た目のジオメトリは不変。style op (undo 可能)。

## 断念した代替案

- **エッジ中心への固定**: 現在位置を保存する方がユーザーの
  意図 (見ている接続点をそのまま固定) に一致。

## 影響

- `s.a||s.b` のコネクタ選択時に ctx 行が出る。⌥-drop で
  作った固定アンカーもここから解除可能。
