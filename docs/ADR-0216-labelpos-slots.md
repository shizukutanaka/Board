# ADR-0216: ラベル位置のスロット吸着

## 状態

実装済み (v1.7.274)。

## 背景

コネクタラベルの `labelPos` ドラッグは中心 0.5 のみ磁石だった —
draw.io の label 位置は start/center/end (0/0.5/1 系) の決定的
スロットに吸着するのが慣例で、端点寄せ・四分割寄せを手動で
正確に置くのが難しかった。

## 決定

`t` を `[0,0.25,0.5,0.75,1]` の5スロットに ±0.03 で吸着
(従来の中心磁石を一般化)。どちらの端にも確実に寄せられる。

## 断念した代替案

- 端点のみ (0/1) 吸着: 四分割も flow diagram で頻出するため
  5スロットにした。

## 影響

- ラベルドラッグ UX のみ。保存形式不変。
