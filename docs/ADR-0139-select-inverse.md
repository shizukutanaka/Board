# ADR-0139: 選択の反転

## 状態

実装済み (v1.7.196)。

## 背景

「今選んでいるもの以外」を選ぶ手段が無い — draw.io の ⌘⇧I /
Photoshop の反転選択に相当。疎な部分集合の除外に使う。

## 決定

- `selectInverse()` — 未ロックかつ可視の全図形から現在の選択を
  除いた補集合を新しい選択とする (マーキー/⌘A と同じ
  フィルタ規則)。
- キー: ⌘⇧I (⌘I は italic なので ⇧ 付き)。ctx: 「選択を反転」
  (盤面が空でない時のみ表示)。

## 断念した代替案

- **shift+click を繰り返す手動操作**: N 個の反転は N 回クリック —
  本機能は一回で済む。

## 影響

- 補集合が空なら選択は空になる (トーストは `_announceSel` が
  カバー)。
