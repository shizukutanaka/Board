# ADR-0163: Tab サイクルから非表示図形を除外

## 状態

実装済み (v1.7.221)。

## 背景

ADR-0137 の「非表示」(`visible===0`) は全ポインタ経路から除外済み
(hit/marquee/lasso/measure) だが、Tab キーの選択サイクルだけは
`!s.locked` のみで絞っており非表示図形を選択できていた — ポインタで
触れない図形がキーボードで選択できる不整合。SR 利用者は「選択したが
画面に無い」混乱を受ける (DOM mirror には `(非表示)` 注記があるが、
選択しても編集経路が塞がる).

## 決定

Tab サイクルの対象フィルタに `s.visible!==0` を追加
(`filter(s=>!s.locked&&s.visible!==0)`)。非表示図形の再表示は
全選択→ctx「再表示」経路 (ADR-0137) が既に存在するため到達手段は
失われない。

## 断念した代替案

- **非表示を末尾に回す**: 回しても選択=編集不能の行き止まりは同じ。

## 影響

- ADR-0150 の hidden-path 監査の最終ピース (Tab cycle) を閉じる。
