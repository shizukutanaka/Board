# ADR-0162: ダブルクリックでグループ内メンバーを選択

## 状態

実装済み (v1.7.220)。

## 背景

グループ化した図形はクリックすると全体が選択される (Figma 式) が、
個別メンバーを操作するには一度 ⌘⇧G で解除→再グループが必要だった。
Figma はダブルクリックでグループへ「潜り」クリックした子を選択する。

## 決定

dblclick ハンドラ冒頭: `hit.groupId` があり、かつ現選択がその
グループ全体を既に包含している場合に限り、選択をクリックした
メンバー単体に絞る (`new Set([hit.id])` + `_announceSel`)。
2回目の dblclick は従来通りラベル/テキストエディタを開く —
潜り→編集の2段ジェスチャは Figma と同一。

グループ未選択状態での dblclick (直接ラベル編集したい場合) や
ロック中は従来挙動を維持。

## 断念した代替案

- **dblclick を常にメンバー選択に**: 初回 dblclick (未選択状態) で
  ラベル編集が到達不能になり後退。
- **⌘dblclick 等の修飾子**: 発見性が低く Figma parity から外れる。

## 影響

- 選択状態のみの変更。シーン・履歴・共有に影響なし。
