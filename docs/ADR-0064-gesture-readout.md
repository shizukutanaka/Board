# ADR-0064: ジェスチャー中のライブ寸法表示 (readout pill)

## 状態

採用 (v1.7.122)

## 背景

draw.io ではリサイズ中に W×H、回転中に角度が対象近傍にピル表示される;
Figma も同様の寸法オーバーレイを持つ。Board はグリッドスナップ/整列ガイドは
出るが「いま何×何か」「何度か」「どれだけ動いたか」はポインタを離すまで
分からず、正確な配置には数値の目視が要る。

## 決定

render-only の `state.readout={x,y,label}` (world coords, アンカー=対象の
下端中央) を追加し、`drawOverlay` がスナップガイドと同じ層にピル描画:

- **resize** (`applyResize`): `W × H` — 単体・複数選択 (vbox 経由) ・pen の
  pts bbox が同一経路でカバーされる。`p1`/`p2` 端点ハンドルは接続長 `↔ N`。
- **move** (`moveDelta`): `+dx, −dy` — スナップ適用後の最終オフセット。
- **rotate** (単体): 絶対角 `N°` (knob-up=0、Shift=15° スナップ反映)。
- **grot** (複数): デルタ角 `±N°`。
- クリアは `state.guides=null` と同じ全クリーンアップ点で行う
  (pointerup/abort/escape)。ドラッグ経路以外では触らないので残存しない。
- ピルは `--ink` 85% 背景 + 白文字、対象下端 14px 下 — ドラッグ中の
  ポインタを遮らない位置。数値のみで文言を持たないため i18n 不要。
- `applyResize` の vbox 呼出がそのまま複数選択 readout になるため
  `_gresizeDrag` 側の追加コードは不要。

## 断念した代替案

- **ツールチップ/div での DOM 表示**: オーバーレイ canvas ピルの方が
  毎フレーム同期・transform 追従で簡単 (DOM は再レイアウトコスト)。
- **カーソル横に表示**: ポインタに被る (draw.io が対象下端に出すのは
  そのため)。固定ステータスバー欄は視線移動が大きい。
- **marquee/描画中にも表示**: 描画ツールは draft で値が自明
  (マーキー幅高も表示価値は薄い) — 変換ジェスチャーに限定。

## 影響

- リサイズ/移動/回転中にライブ数値が対象直下に出る。精度作業が
  ポインタを離さず完結。render-only でモデル・undo・同期に無関与。
