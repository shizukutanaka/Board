# ADR-0179: 画像キャプションの上下位置

## 状態

実装済み (v1.7.237)。

## 背景

画像キャプション (ADR-0083) は常に画像下部の帯 — draw.io では
キャプションを上/下に配置できる。「上にタイトル」を付けたい
需要は画像の用途として自然。

## 決定

`s.valign` を画像へ拡張: `cycleVAlign` の型ゲートに
`(s.type==='image'&&s.label)` を追加し、`_drawImgLabel`/
`_svgImgLabel` で `valign==='top'` → キャプション帯を画像上部に
描画 (null/bottom → 従来の下部)。ctx「ラベル縦揃え」はラベル所持
の画像でのみ表示。

## 断念した代替案

- **独立プロパティ `capPos`**: `valign` の語義と重複 — 既存キーを
  画像意味 (キャプション側) にマップする方が style 体系を壊さない。

## 影響

- `s.valign` 未設定の画像は従来通り下部キャプション。style op
  経由で undo/sync 適合。
