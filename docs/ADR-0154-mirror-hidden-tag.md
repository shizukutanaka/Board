# ADR-0154: DOM ミラーで非表示図形に (非表示) タグ

## 状態

実装済み (v1.7.212)。

## 背景

ADR-0041 の DOM ミラー (スクリーンリーダー向け図形一覧) は
非表示図形を通常図形と区別なく列挙していた。ミラー経由の
`_mirrorGo` は「選択+fit」なので、不可視の図形が選択される
とユーザーは「何も選べなかった」ように見える。

## 決定

- ミラーの列挙に `s.visible===0` 時は i18n タグ `(非表示)`
  を付記。**除外はしない** — ミラーは SR ユーザーが隠れた
  図形の存在を知る唯一の経路であり、除去は情報の消去になる
  (復帰は ⌘⇧H / ctx「すべて表示」が既存)。

## 断念した代替案

- **一覧から除外**: 見た目との一貫性は取れるが、SR 環境では
  隠し図形を発見する術が完全に消える — 誠実な状態表示を選択。

## 影響

- a11y ミラーの文言のみ。i18n `tagHidden` を ja/en に追加。
