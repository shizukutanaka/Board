# ADR-0396: 全選択ロック時の Delete 警告トースト

## 状態
実装済 (v1.7.434)

## 背景
`doDelete` は `_selL(s=>s&&!s.locked)` でロック済みを除外するため、選択が全部
ロック済みだと `!sel.length` で無言 return していた。キーボード利用者は
「Delete が効かない」理由が分からない。

## 決定
空選択時に `_selAny()` (選択自体は存在する) なら `lockedNoop` トーストを出す。
文言は ja/en で「ロック済み — ⌘⇧L で解除」。Excalidraw は削除自体をボタンで
グレーアウトするが、Board は ctx メニューでのみ同様のガードがあるため、
キーボード経路ではトーストが最も安い手段。

## 影響
何も選んでいないときの Delete は従来どおり無言 (誤爆しない)。
