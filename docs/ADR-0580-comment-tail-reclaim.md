# ADR-0580: コメント尾の一括刈り込み (~17.9KB 回収)

## 状態
実装済み (v1.7.607)

## 背景
raw 512KB 上限まで残 ~19B まで消耗していた。shorthand/fold の機械的削減
空間は枯渇済み (ADR-0476..0515) のため、残る最大の余剰は**長い説明コメント
(≥70 字の行内コメント)** だった。

## 決定
以下のガードを設けてコメント尾のみを短縮 (head のコードは不変):

- 行頭が `//` のみのコメント行、またはコード後の行内 `//` コメントで
  コメント部が ≥70 字のものだけ対象
- `://` / `data:` / `svg+xml` / `%2` / `w3.org` / `url(` / `======` バナーを
  含む行は除外 (URL・データ URI・区切り線の破壊防止)
- head (コード側) に引用符を含む行は除外 (`//` が文字列内の誤検出防止)
- **コメント先頭 30 字が test.mjs に含まれる行は除外** — ソースピンが
  コメント文字列を参照する場合の破損防止 (本パスでも1件検出し手動復元)
- 切り詰めは 45 字まで + 単語境界 rstrip

## 影響
- 506,241B / 余白 ~18KB — 実害修正のためのバイト枠を再確保
- 読みやすさを大きく損なわない範囲での圧縮 (長文の前置き説明を保持)
