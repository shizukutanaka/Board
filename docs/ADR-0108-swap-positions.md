# ADR-0108: 位置を入れ替え (ctx「Swap」)

## 状態

実装済み (v1.7.166)。

## 背景

2つの形状の位置を交換するには手動ドラッグ×2が要る — Figma の
「Swap positions」に相当する1クリック操作が無い。

## 決定

- `doAlign` に `dir:'swap'` — units.length===2 のみ発動、両 unit
  を相手の bbox 中心へ平行移動 (サイズ・回転は不変)。
- ctx `ctxSwap` (選択2のみ表示)。

## 断念した代替案

- **bbox 左上合わせ**: サイズ差でズレが残る — 中心合わせが自然。
- **N≥2 巡回シフト**: 用途が曖昧 — 2選択限定で単純に。

## 影響

- `align` op (dir:'swap') で一括 undo、共有同期は既存経路。
- `DIRS` ホワイトリスト更新 (test 更新済)。
