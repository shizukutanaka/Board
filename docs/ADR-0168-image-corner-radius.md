# ADR-0168: 画像の角丸

## 状態

実装済み (v1.7.226)。

## 背景

ADR-0136/0156 で rect/diamond に角丸 (`s.r` + ctx「角丸」巡回) を
導入したが画像は対象外 — スクリーンショット等の矩形が常に鋭角。

## 決定

- `cycleCorner`/`ctxCorner` の型ゲートに `image` を追加
  (同一シーケンス 8→16→24→0)。
- canvas: `s.r>0` のとき `roundRect` クリップで `drawImage` を
  制約 — `s.flip` の局所軸変換はそのまま同居 (クリップはワールド
  座標で先に適用)。
- SVG: `<clipPath id="irc{id}"><rect rx=…>` を emit し `<image>`
  に `clip-path` 属性 — 回転・フリップ変換と独立。
- `min(|w|,|h|)/2` でキャップ (楕円化上限)。ヒット判定は矩形の
  まま (角部ヒットは全ツール共通の許容差)。
- ミニマップは未クリップ (~2px で知覚不可、走査コスト回避)。

## 断念した代替案

- **画像専用シーケンス**: ctx 項目増加より既存「角丸」への合流が
  発見性・コード量とも有利。

## 影響

- style op 経由で undo/sync 適合。`s.r` は画像にも流用
  (validPatch 通過、リモート・ファイル両経路で保持)。
