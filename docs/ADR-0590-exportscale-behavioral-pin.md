# ADR-0590: exportScale のクランプを実動作テストで固定する

## 状態

実装済 (round299)。テストのみ。

## 背景

大盤面の PNG/PDF エクスポートがブラウザのキャンバス上限 (~16384px/辺・面積) を超えて
空白化する問題は `exportScale` のクランプで解消済み (spec §14.2 残項の一つ) が、
ソースピンのみで実動作の検証がなかった。クランプが外れたり条件順序を変えたりしても
「常に非空白の出力が得られる」ことが保証されない。

## 決定

`test.mjs` に behavioural テストを追加:

- 小盤面 (`10×10`, desired 2) → 2 のまま (クランプ発動しない)
- 巨大盤面 (`40000×40000`) → `16384/40000` 以下にクランプ
- ワイド盤面 (`20000×10`) → 辺上限でクランプ
- 面積上限 (`20000×20000`, desired 1) → 面積 ≤ `16384²`
- 退化 bbox (`0×0`) → NaN にならない

## 影響

- 大盤面エクスポートのリグレッションを検出可能に。
