# ADR-0315: リンクバッジをスクリーンリーダーにも通知

## 状態
承認 — round51

## 背景
🔗 バッジ (ADR-0310) は視覚のみ。`describeShape` が選択時の
ライブリージョンに「リンクあり」を含めなかったため、
SR 利用者は ctx「リンクを開く」の存在を知れなかった。

## 決定
`describeShape` 末尾に `if(s.link)d+=' 🔗'` を追加 — 視覚バッジと
同じ絵文字で対応を保つ。

## 断念した代替案
- `t('hasLink')` 文言 — i18n 2語増 vs 絵文字1つの効果同じで後者採用
  (絵文字は SR が「リンク」と読み上げる)。

## 影響
選択通知にリンク存在が含まれる。2023 全緑。
