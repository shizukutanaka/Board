# ADR-0176: 画像のボーダー

## 状態

実装済み (v1.7.234)。

## 背景

`s.stroke`/`s.size` は塗りボタンやスタイルコピー経由で画像にも設定
できたが、描画経路が無視していた — 白っぽい画像を盤面から浮かせる
枠が引けなかった。draw.io/Miro では画像にボーダーを付けられる。

## 決定

`s.stroke && s.size` の両方が揃った時、角丸半径 `s.r` (ADR-0168) に
倣った roundRect ボーダーを canvas と SVG で描画。読み込み前の
プレースホルダ枠 (`#CBD5E1`) は従来通り。

## 断念した代替案

- **stroke のみでボーダー (size 既定2)**: `size` は既存の線幅語彙 —
  ボーダー幅として再利用するのが一貫。両方要求することで「線色は
  持つが線幅なし」の画像が意図せず枠付きになるのを防ぐ。

## 影響

- ボーダー未設定の画像は不変。キャプション (`_svgImgLabel`) の
  文字色は従来から `s.stroke` を参照 — ボーダー色と同色になる
  (一貫)。
