# ADR-0113: 同じ位置に貼り付け (⌘⇧V)

## 状態

実装済み (v1.7.171)。

## 背景

貼り付けは2経路ある — ⌘V はビューポート中央+カスケード、
ctx「ここに貼り付け」(ADR-0103) はメニュー開放点 — が、
**コピー元と同じ座標**に貼る経路が無い。Figma の
Paste-in-place (⌘⇧V) 相当で、別ビュー/ボード間で図形を
同じ座標に移す用途が多い。

## 決定

- `doPasteInPlace()` — `_placeCopies(shapes,0,0)` で元座標に
  複製。同じボード上では元の真上に重なる (Figma 同様)。
- `⌘⇧V` バインド。既存の `meta&&k==='v'` は shift 非排他だった
  ため `!e.shiftKey` を追加して分割 (⌘⇧V が従来ペーストに
  吸収されないよう修正)。
- ctx メニューにも `ctxPasteInPlace` を追加。

## 断念した代替案

- **小さなオフセット付き**: ずらすと「同じ位置」の意味を失う。

## 影響

- ⌘V (ビューポート中央+カスケード) / ここに貼り付け (指定点) /
  ⌘⇧V (元座標) の3経路が揃った。
