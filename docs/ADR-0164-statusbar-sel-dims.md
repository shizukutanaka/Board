# ADR-0164: ステータスバーの選択寸法表示

## 状態

実装済み (v1.7.222)。

## 背景

Figma/draw.io は選択中の図形に W×H の寸法を常時表示する — 揃え・
サイズ調整の基礎情報。Board のステータスバーは座標のみで、選択
bbox の寸法を見る手段が無かった。

## 決定

- ステータスバーに `sSel` 項目を追加 (`x,y` の右)。非選択時は
  `hidden` で折り畳み。
- `frame()` 末尾で `_statusSel()` を呼ぶ — 選択の変更は必ず
  invalidate を伴うためこの一点で全変更を捕捉 (ADR-0011 と同じ
  パターン)。`G.bboxAll(sel)` の W×H を四捨五入して表示。
- DOM 書き換えはテキストが変わった時のみ (signature `_selDimSig`)
  — ジェスチャ中のフレームでは bboxAll+文字列比較のみ。

## 断念した代替案

- **_announceSel でのみ更新**: リサイズ/ドラッグ中の寸法変化を
  取り逃す (選択は変わらず bbox だけが動く)。
- **ツールバー上の寸法フィールド**: Figma の入力可能フィールドは
  値編集 UI を要し今回の範囲外 — 読み取り専用表示とした。

## 影響

- DOM は `UI` セクションではなく frame() からの書き込みだが、
  `sSel` span は読み取り専用ラベルで XMark注入の余地なし
  (数値のみ)。
