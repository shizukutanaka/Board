# ADR-0142: フリップ時の回転角ミラーを軸別に修正 (バグ修正)

## 状態

実装済み (v1.7.199)。

## 背景

`flipShape` は回転済み図形の `s.rotate` を両軸とも `360−θ` に
していた。正しい鏡像は、x ミラー ('h') が `180−θ`、y ミラー
('v') が `360−θ`。矩形等の 180°対称図形では 330° と 150° が
見かけ同一だったため長年見逃されていたが、**テキスト/付箋は
上下が読めるため 180°ずれは倒置になる**実バグ。

## 決定

- `s.rotate=((axis==='h'?180:360)-s.rotate+360)%360`。
- 既存テストはバグ値 330° を 'h' で期待していたため、正しい
  150° に更新し 'v'→330° の検証を追加。

## 断念した代替案

- **回転をクリア**: 単純だが「向きを保ったまま反転」する
  ユーザ意図に反する。

## 影響

- 回転していない図形・点ジオメトリには無影響。
