# Board — カテゴリ別 徹底監査 (2026-06, v1.6.17)

プロダクトを 12 カテゴリに分割し、各カテゴリの実装(`index.html`)を精査して改善点を
洗い出した記録。`✅`=本監査(v1.6.17)で修正、`⬜`=今後(予算/リスクで保留、根拠を併記)、
`✓`=既に妥当(誤検知を含む検証結果)。gzip 予算が逼迫(残 ~1.5KB)のため、
本監査は**新機能でなく正確性・堅牢性・a11y・一貫性**の修正を優先した。

---

## 1. レンダリング (draw / drawShape / drawPen / 他)
- ✅ **線種の dash がフレーム間/図形間で漏れない**: `drawShape` 末尾で `setLineDash([])` を無条件リセット
  (v1.6.16 で導入済みを確認)。
- ✓ pen の `lineWidth/lineCap/lineJoin` はループ後に復元済み(誤検知)。
- ✓ sticky の影 (`shadowBlur/OffsetY`) は描画直後に 0 へ復元済み(誤検知)。
- ✓ `draw()` は frame を背景層、その他を前景層として全種別を描画(culling は全種に適用)。
- ⬜ DPR と選択ハンドルの dash スケール差(視覚的軽微)。bytes 優先で保留。

## 2. 入力 / ツール (pointer / keyboard / wheel)
- ✓ ペン筆圧 `_penPr` は有限値強制済み。
- ✓ 移動の delta は `moveDelta` で live/commit 一致。
- ⬜ キーボードでのリサイズ/回転は未対応(作成・巡回・移動は対応済み)。

## 3. 状態 / Store / Undo
- ✓ 全 op が `_apply(op,false)` で可逆(property-based test 30 シナリオで往復検証)。
- ✓ `seenOps` は `MAX_SEEN_OPS` で上限管理。
- ⬜ `zorder` op の全 shape スナップショット(大規模で履歴肥大)→ fractional index 化は専用 ADR 予定。

## 4. 幾何 / ヒットテスト / スナップ
- ✅ **pen の不正 `pts` でのクラッシュ防止**: `validShape` が intake で `pts` 配列+有限座標を検証
  (drawPen/G.hit/G.bbox は `pts[i][0]` を参照するため、null/空/非配列で描画・hover 時にクラッシュしていた)。
- ✓ `pickTop` は空間グリッドで候補を絞り `G.hit` で確定(v1.6.11)。
- ⬜ リサイズ時のオブジェクトスナップ(移動のみ対応)。

## 5. 永続化 (IndexedDB)
- ✅ **viewport の有限性検証**: `load` 時に `x/y/zoom` が有限かつ `zoom>0` の時のみ採用
  (NaN viewport が保存されると全ズーム計算が壊れていた)。
- ✅ **全 intake で `validShape` 共有**: load も他経路(import/snapshot)と同条件。
- ✓ `save` は `txDone` 成功後のみ `dirty=false`(失敗時は dirty を維持し再試行、誤検知)。
- ✓ open/load 失敗時も main の try/catch で in-memory 起動継続。

## 6. 同期 / リモート op
- ✅ **remote `add` も `validShape`**: pen 不正 pts をネットワーク経由で注入してもクラッシュしない。
- ✓ `applyRemote` は op 型 allow-list + `validRemotePayload`(全 op 構造 + 有限 delta)。
- ✓ `clone()`=JSON で prototype 汚染無効化。
- ⬜ snapshot の rect/line 等の座標有限性は未検証(pen のみ強化)。malicious 入力時の NaN 座標は
  描画クラッシュには至らない(canvas は NaN を無視)が、`fitToContent` 等で NaN viewport を生む余地。
  低頻度・低危険のため次回。

## 7. エクスポート (PNG / SVG / PDF)
- ✓ SVG は数値 `_num` 強制 + 文字列 `_esc`、`href` は `data:image/` のみ。
- ✓ 線種 dash・可変幅 pen・sticky wrap は canvas/SVG パリティ済み。
- ✓ group の破線ボックスは編集アフォーダンスのため export 非対象(設計通り)。
- ⬜ SVG の sticky 折返しは概算メトリクス(`length*fs*0.6`)で canvas の `measureText` と微差。
  メトリクステーブル導入は bytes 高。許容範囲として保留。

## 8. セキュリティ / 検証
- ✅ **共有 `validShape` で intake を一元化**(load/import/snapshot/remote add)。
- ✓ `innerHTML=` 不使用(CI grep)。SVG/PDF 出力の属性は全エスケープ。
- ⬜ 画像 dataUrl の import 時 `data:image/` 検証は未実施(export 時は検証済み・img は script 実行不可のため低危険)。

## 9. アクセシビリティ
- ✅ **モーダルが Escape で閉じる**: `#help`/`#share` は `aria-modal` だが Escape 未対応だった
  (WCAG: ダイアログは Escape で閉じられること)。Escape ハンドラでモーダルを優先的に閉じる。
- ✅ **`.dashbtn` を forced-colors 対応**: 線種ボタンが Windows ハイコントラストで不可視だった
  → `border:1px solid ButtonText` に追加。
- ✓ `prefers-reduced-motion` は animation/transition 双方を 0.01ms に(toast も対象、誤検知)。
- ✓ canvas に role/aria-label/tabindex、Tab 巡回 + Enter 作成を明記。
- ⬜ モーダルの focus trap / 復帰は未実装(Escape 閉じは対応)。半端な部分実装は避け保留。
- ⬜ ツール変更時の canvas aria-label 動的更新(tool ボタンの aria-pressed で代替中)。

## 10. i18n (ja / en)
- ✅ **en の欠落キー補完**: `ctxDelete`(削除)/`ctxBringFront`(最前面へ)が en に無く、英語環境で
  右クリックメニューに `undefined` が出ていた → 追加。使用キー 45 個を ja/en 突合し他に欠落なしを確認。

## 11. PWA / オフライン
- ✓ インライン manifest + Service Worker(cache-first)。初回後オフライン等価。
- ⬜ SW のキャッシュ版数更新時の旧キャッシュ purge 戦略は要点検(次回)。

## 12. UI / UX
- ✅ **画像キャッシュの上限化(LRU)**: `_imgCache` が無制限増加で多数画像貼付時にメモリリーク
  → 上限 60、アクセスで再挿入(LRU)、超過時に最古を削除。
- ⬜ 選択時にスタイルパネルが対象図形の値を反映しない(全コントロール共通の既存制約)。

# 第2弾(深掘り) — v1.6.18

ツールハンドラ / キーバインド / テキスト編集 / プレゼン / viewport / クリップボード /
消しゴム / コンテキストメニューをサブシステム単位で精査。2 つの read-only エージェントで
網羅し、各指摘を本体コードで検証してから対応(誤検知は不採用)。

## 修正(4 件)
| # | カテゴリ | 重大度 | 内容 |
|---|---|---|---|
| 1 | 入力/キーマップ | **P1** | 平打ち `p` がプレゼンに横取りされペン到達不能 → `p`=ペン / `⇧P`=プレゼンに分離 |
| 2 | プレゼン | **P1** | `enter`/`leave` で viewport 保存・復元(Esc 後に最終フレームへ取り残される問題) |
| 3 | i18n | **P1** | ヘルプ表の 'プレゼン'/'移動'/'前面/背面'/'最前面/最背面' を i18n 化(英語環境で日本語表示) |
| 4 | 幾何/リサイズ | P2 | pen をボックスハンドル非表示(移動のみ)に。box-resize が `x/y/w/h` を NaN 化していた |

## 検証して不採用(誤検知)
- `doPaste` のクリップボード offset 加算 → **意図通り**(各ペーストを少しずつずらす一般的 UX)。
- `doUngroup` がグループ全体を解除 → **正しい ungroup 意味論**(メンバー選択は通常グループ全体に展開)。
- `fitToContent` のゼロ面積除算 → `Math.min(zx,zy,2)` の `,2` 上限で `Infinity→2`、NaN にならず**安全**。
- `flushErase` の z 順序 → `sortZ()` が復元、`_apply` も sortZ。**正しい**。
- テキスト新規空文字の undo / `positionTextEditor` の DPR → 検証の結果**問題なし**。
- ピンチ解除 (`_pointers.size<2`) / コンテキストメニュー位置(可視化後に計測)→ **正しい**。

## 残課題(保留)
- ⬜ pen の真のリサイズ(pts スケール):現状は移動のみ。スケール実装は将来(bytes)。
- ⬜ テキスト編集中の pan/zoom 追従(モーダル的なので影響小)。
- ⬜ min/max ズーム到達時の zoomAt のわずかなパン(視覚的軽微)。

検証: テスト 219/219 全通過、gzip 43.7KB(予算 45KB)、innerHTML/外部依存/構文 全 clean。

read-only エージェント 1 体 + 本体コードでの逐次検証。

## 修正(2 件)
| # | カテゴリ | 重大度 | 内容 |
|---|---|---|---|
| 1 | 同期(スナップショット) | **P1** | `_sendSnapshot` が全 op に `seq:0` を付与 → `applyRemote` の `peer:seq` dedup で**マージ時に先頭 1 図形のみ適用**。一意 `seq:'snap'+i` 付与 + マージは既存 id を skip |
| 2 | PWA | P2 | `activate` で旧 `board-v*` キャッシュを purge(リリースごとに滞留していた) |

## 検証して不採用(誤検知)
- `seenOps` の 20% トリム → **挿入順=最古から削除**で、最古 op は再受信されにくく**正しい**設計。
- `seq` 開始値 0 → スナップショットを `'snap'+i` 化したことで実 op(数値 seq)と非衝突。問題なし。
- DataChannel の `JSON.parse` を空 catch → クラッシュ防止の防御的処理。許容。
- `escape/unescape` + `RTCSessionDescription` → 非推奨だが SDP は ASCII で機能。実害なし。
- `importFromHash` → 既に try/catch で警告ログ + false 返却。許容。
- BroadcastChannel エコー防止(`msg.peer===state.peerId`)→ 正しく機能。

## 残課題(保留)
- ⬜ 完全な CRDT マージ(変更済み図形の更新)。現状マージは「未保有図形の取り込み」のみ。
- ⬜ WebRTC トークンの近代化(base64 直)・import 失敗時のユーザ通知。bytes 優先で保留。

検証: テスト 223/223 全通過、gzip 43.9KB(予算 45KB)、innerHTML/外部依存/構文 全 clean。
