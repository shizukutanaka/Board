# ADR-0125: マーカー (ハイライター) ツール

## 状態

実装済み (v1.7.182)。

## 背景

ペンは細く不透明 — 手書きの強調 (テキスト上のアンダーライン、図形
のハイライト) に向かない。Miro/draw.io は専用のハイライターを持つ。

## 決定

- 新ツール `marker` — ツールバー (ペンの隣) + `K` キー
  (M はミニマップに割当済み)。
- 実体は **pen シェイプ + `hl:1`**: 生成時に `size=8, opacity=0.4`
  を焼き、`contPen` の圧力サンプルを 0.5 に固定 (フラット線)。
- 新しいシェイプ型・新しいレンダ経路は作らない — alpha は既存の
  `s.opacity` 経路で draw/SVG/ミニマップ全てに自動適用。

## 断念した代替案

- **`multiply` ブレンド**: 重なりで暗くなるハイライター表現は
  キャッシュ bitmap 合成と相性が悪く (multiply は合成時に要る)、
  ダークテーマで無効化が要る — alpha だけで十分ハイライターに
  見えるため見送り。
- **ctx「ハイライターに変換」**: フラグは単なる既定値の違い —
  既存の透明度スライダで同等にできるので変換項目は不要。

## 影響

- `hl` は描画上の振る舞い (圧力フラット化) のみで、永続化・
  ワイヤ・validShape は透過 (未知 prop は validPatch で既に
  検査済み)。
