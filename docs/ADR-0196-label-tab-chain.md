# ADR-0196: ラベル編集の Tab 巡回

## 状態

実装済み (v1.7.254)。

## 背景

複数図形に連続してラベルを付ける場合、毎回 dblclick または
Enter が必要だった。Figma/draw.io のセル編集と同じく、Tab で
「確定 → 次へ」を一発化する。

## 決定

ラベルエディタの Tab/Shift+Tab で: コミット → `state.shapes` を
順方向/逆方向に巡回し、次のラベル対応図形 (非ロック・非表示、
`_lblAnchor` が anchor を返す全型) を選択してエディタを開く。
巡回は全周しても到達不能なら単にコミットして終了。

## 断念した代替案

- **z-order ではなく位置ソート**: 巡回順は作成順 (state.shapes)
  が最も予測可能 — 位置ソートは隣接方向と一致しない。

## 影響

- Tab 単体の既存動作 (フォーカス遷移) はエディタ内で抑止 —
  従来もフォーカス先が無かったため実害なし。Escape は従来通り
  キャンセル。
