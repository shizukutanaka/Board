# ADR-0157: ctx「結合を解除」 — 選択コネクタの a/b を一括クリア

## 状態

実装済み (v1.7.215)。

## 背景

コネクタの端点結合は「ドラッグして空白に離す」しか解除手段が
なかった — フローチャートの一部を複製・移動する際、数十本の
結合を一本ずつ解除するのは非現実的。draw.io の "Detach" 相当。

## 決定

- `unbindSelection()` — 選択中の line/arrow で a/b が存在する
  ものを `a=b=null` に (座標は現在値で固定 = 見た目不変)。
  通常の style op なので undo/LWW は既存機構。
- ctx ゲート: 結合済みの未ロックコネクタが選択に1本でもある時。

## 断念した代替案

- **⌥click 端点で解除**: 端点への ⌥click 文法は route-reset
  系 (cbend/labelPos/way) に充て済み — 結合解除は破壊的方向
  なので明示的メニュー項目が適切。

## 影響

- i18n `ctxUnbind` ja/en 追加。undo は before/after に
  a/b+座標を含めて完全復元。
