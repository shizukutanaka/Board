# ADR-0202: 新規描画中の寸法/線長リードアウト

## 状態

実装済み (v1.7.260)。

## 背景

既存シェイプのリサイズ/線ドラッグには `state.readout` の寸法/長さ
ピルがあるが (3242/3262)、**新規** rect/ellipse/diamond/sticky/frame の
ドラッグ描画と line/arrow の始点→終点ドラッグでは無表示だった —
最も頻繁な「描きながら寸法を合わせる」局面で情報が欠けていた。

## 決定

- `contRectLike`: `state.readout={x:中心,y:下端,label:'W × H'}`
- `contLineLike`: `↔ 長さ` (既存線の 3262 と同形式)

いずれも ptr.wx0/wy0 (始点) と現在終点から算出、readout は
pointerup で既存経路により消去。

## 断念した代替案

- **ペンドラフトの長さ表示**: パス長は自由曲線では意味を持たない。

## 影響

- グリッド吸着と併用して目標寸法ぴったりに描画できる。
