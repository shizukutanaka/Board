# ADR-0198: コネクタ方向の反転

## 状態

実装済み (v1.7.256)。

## 背景

draw.io の "Reverse" 相当が欠けていた — 矢印の向きを変えるには
引き直しか、両端を再ドラッグするしかなかった。図形に結合された
フローチャートでは結合先の付け替えも伴い実質作り直し。

## 決定

`reverseConn` (ctx メニュー「方向を反転」)。x1,y1↔x2,y2・
a↔b 結合先・way 順序を入替、labelPos は 1-pos に鏡像化。
style op なので undo で完全復元・peer に反映。

`s.head` (終端ヘッドスタイル) と `s.start` (始端ヘッド有無)
はそのまま保持 — 端点交換で「見た目のヘッドの位置」が自然に
入れ替わるため (片頭矢印は逆向きの片頭に、両頭は両頭のまま)。
bend/cbend は世界座標のルート修飾で方向に依存しないため不変。

## 断念した代替案

- **`s.start` を反転時に消去**: 旧終端のヘッドが消えて忠実な
  反転にならない。
- **labelPos を据置**: ラベルがルートの別位置に飛ぶ。

## 影響

- way 無しの単純コネクタでも結合端点の付け替えが1クリックに。
- elbow/curve の修飾は反転後も有効 (経路形状は同じ弓側)。
