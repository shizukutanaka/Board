# ADR-0071: 等間隔スナップ (equal-gap smart guides)

## 状態

採用 (v1.7.129)

## 背景

objectSnap は他図形のエッジ・中心への吸着を提供するが、draw.io の
「等間隔ガイド」(ドラッグ中の図形が隣接図形と**既存間隔と同じ隙間**を
作る位置に吸着し、等しい2区間をガイド表示) は未実装。整列済み行/列の
中間への挿入が現状では目測。

## 決定

- `_eqGapSnap(mov,excl,tol)` を objectSnap に追加: エッジ吸着が成立
  しなかった軸でのみ評価 (コスト最小化 + エッジ優先の競合回避)。
- X 軸: mov の y-band と重なる図形を x ソート → 連続ペア (a,b) の
  正の間隔 `g = b.x−(a.x+a.w)` を収集。候補位置は
  `x = b.x−g−mov.w` (a→b と同じ g を左側に) と `x = a.x+a.w+g`
  (a から g 右側)。Y 軸は対称。
- 吸着時のガイドは**等しい2区間を示す短い横線**。
- tol は `SNAP_OBJ/zoom` (エッジ吸着と同一基準)。

## 断念した代替案

- **全間隔の組み合わせ探索**: 任意の2区間ペアは O(k²) — 連続ペアのみで
  実用十分 (draw.io も同じヒューリスティック)。
- **中央揃えスナップ (中点吸着)**: 等幅の場合は等間隔と同値 — 非等幅の
  「ギャップ中央」は別概念で今回対象外。
- **常時評価**: エッジ吸着と同時成立時にどちらを表示するか曖昧になる
  のを避け、エッジ優先 + 未成立軸のみ。

## 影響

- `moveDelta` → `objectSnap` の内部追加のみ — op・モデル不変。
- エッジ吸着が無い位置でも等間隔吸着が発火して整列作業が高速化。
- コストは未成立軸のみ O(row) の y-band フィルタ + ソート。
