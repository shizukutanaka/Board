# ADR-0150: 非表示図形の残存経路整理 (検索・バインド)

## 状態

実装済み (v1.7.207)。

## 背景

ADR-0137 の `s.visible===0` は描画・ヒット・マーキー・選択系を
網羅したが、2経路が残っていた:
- **検索** — 見えない図形にマッチしてもユーザーは確認不能
- **端点バインド** (`_bindAt`) — 不可視の図形への結合は
  宙に浮く矢印を生む

## 決定

- `_sqList` 構築で `s.visible!==0` をフィルタ。
- `_bindAt` の候補走査で `s.visible===0` をスキップ
  (ロックは引き続き結合可 — ロックは編集禁止であって
  存在の消去ではない)。
- 既存のバインド関係は維持 — 「非表示にすると結合が消える」
  とはしない (connClears は削除のみを対象とする設計のまま)。

## 断念した代替案

- **非表示時に結合を自動解除**: 一時的な退避操作で関係性を
  破壊するのは過剰 — 可視化復帰で元通りになる方が自然。

## 影響

- 検索結果・バインド UX のみ。既存ペイロード/undo に無影響。
