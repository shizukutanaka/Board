# ADR-0310: リンク図形に 🔗 バッジ表示

## 状態
承認 — round50

## 背景
ADR-0304 で `s.link` が設定可能になったが、リンクの有無が見た目に
現れず、ctx メニューを開くまで分からなかった。

## 決定
drawShape 末尾で `s.link&&s.w!=null` の図形右上に `🔗` を 10px で
描画 (conn/pen は w が無く頻度も低いため対象外)。

## 断念した代替案
- 下線のみ (Figma 式) — 🔗 の方が発見性が高い。
- conn/pen にも bbox 位置へ描画 — 端点近傍と視覚干渉しやすいため
  box 系のみ。

## 影響
リンク保持図形が一目で分かる。2017 全緑。
