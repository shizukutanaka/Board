# ADR-0576: ピア選択アウトラインが非表示図形を描かない

## 状態
実装済み (v1.7.603)

## 背景
`drawPeerSelections` はピアが送信した選択 id を `byId` で解決して bbox
アウトラインを描くが、`visible:0` を通していた。ピアが図形を選択した直後に
誰か (自分自身含む) がその図形を hide すると、こちらの画面には見えない図形の
位置・サイズの破線枠が残る — hidden parity (ADR-0566/0568) のプレゼンス側
違反であり、非表示図形の存在を他者へ漏らす。

## 決定
`byId` ガードに `_hd` を追加 — deleted/hidden いずれも描かない。
ピアの `p.sel` 配列自体は変更しない (次の presence で解消する)。

## 影響
- 非表示図形の位置情報が peer outline 経由で可視化されない
