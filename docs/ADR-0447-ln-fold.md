# ADR-0447: `X.length` → `_ln(X)` 一括 fold

## 状態
実装済 (v1.7.482)

## 背景
`X.length` 読み取りが単一識別子レシーバで 364 箇所。既存の prop fold
(ADR-0433/0434/0439/0444) と同型だが、`.length` は書き込み開始文字が
読み取りとほぼ同じため、従来の「演算子文字を丸ごとブロック」正規表現では
`x.length-1` や `x.length>=n` といった支配的な読み取り形を逃していた。

## 決定
書き込み開始だけを精密に列挙する否定先読みに刷新して一括 fold:
`(?!\s*(=(?!=)|\+\+|--|+=|-=|*=|/=|%=|&=|\|=|^=|<<=|>>=|>>>=|&&=|\|\|=|??=|**=))`。
`==`/`>=`/`<=`/`&&`/`||`/`??`/`?.`/`-1` 等の読み取りは残り、
`=`/compound-assign/`++`/`--`/`delete` のみ除外される。

def は fold 通過後に mega-const へ挿入 (self-fold 罠回避、ADR-0444 の教訓)。
test.mjs の html.includes/html.match literal は単一・二重引用・regex の
3種を範囲限定で同期。

## 影響
- 364 箇所を `_ln(X)` に fold、raw **~700B 回収** (523,581B → 上限まで ~707B)。
- セマンティクス不変 (`_ln(x)` は `x.length` と同値、文字列・配列・any で等価)。
