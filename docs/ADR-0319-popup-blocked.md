# ADR-0319: リンクオープンのポップアップブロック通知

## 状態
承認 — round53

## 背景
`window.open` はブラウザのポップアップブロックで `null` を返す。
ctx「リンクを開く」・⌘+click の両経路が無言で失敗し得た
(既存の `popupBlocked` i18n キーは PDF 書き出し専用だった)。

## 決定
両 open サイトで `!window.open(...)` → `UI.toast(t('popupBlocked'),'warn')`
に分岐 (既存キー再利用)。

## 断念した代替案
- toast 文言をリンク用に新設 — 「ポップアップを許可してください」
  の要点は同一なので共用で十分。

## 影響
ブロック時にユーザーが原因を把握できる。2027 全緑。
