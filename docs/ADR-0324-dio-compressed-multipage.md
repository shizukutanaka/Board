# ADR-0324: 圧縮 .drawio も全ページ展開する

## 状態
承認 — round56

## 背景
圧縮 .drawio は `<diagram>` ページごとに独立した deflate
ペイロードを持つ。従来は `[^<]+` で先頭 `<diagram>` のみ展開
していたため、圧縮ファイルの複数ページは 2 ページ目以降が
捨てられていた (非圧縮は ADR-0311 で全ページ横並び化済み)。

## 決定
`matchAll` で全 `<diagram>` ペイロードを集め、`Promise.all` +
`_dioInflate` で各々展開 → `<mxfile><diagram>…</diagram>…`
として再ラップして `importDrawioText` に再帰 — 既存の
非圧縮多ページ経路 (ADR-0311) がそのまま全ページを処理する。

## 断念した代替案
- 展開ごとに別 `_cOp` で逐次 addMany — undo が分割され選択も
  中途半端になるため単一ドキュメント化を選択。

## 影響
圧縮・非圧縮で挙動が揃う。2032 全緑。
