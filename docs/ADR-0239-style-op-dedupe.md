# ADR-0239: style op コミットの共有化 (_styleOp)

## 状態

実装済み (v1.7.296)。

## 背景

`{op:'style'}` のコミット定型文 (選択スナップショット
→ `_recordCommitted` → `origSel` 復元) が 27 箇所に
複製され、raw サイズが 512KB 上限に接近していた。

## 決定

`_styleOp(before,after)` ヘルパーを抽出 (ADR-0235 の
`_svgFont` 共有化と同じパターン)。挙動は不変 —
origSel 記録も各サイトで既に同一形だった。

## 影響

- 約3.1KB削減 (523.5KB → 520.5KB)、上限内に余裕回復。
- 今後の装飾 op 追加は呼び出し1行で完結する。
