# ADR-0089: 画像の差替え (Replace image)

## 状態

実装済み (v1.7.147)。

## 背景

画像を別ファイルに置き換えるには、削除→再配置→リサイズ→位置直しと
いう手順しかない。draw.io の "Replace Image" 相当が無い — 同じ
フレーム位置で中身だけ差し替えたい需要 (ロゴ差替、図版更新) は
ホワイトボードでは定番。

## 決定

- `replaceImage()`: 単一選択された未ロック image に ctx メニュー
  「画像を差替え」。動的 `<input type=file accept="image/*">` を
  click し、`_imgImportFile` (既存の 4MB 上限・2048px 縮退と同一経路)
  で読込後、`style` op で `dataUrl` と `h` を差替。
- `h` は `w * nh / nw` で新アスペクトに追従 (x/y/w は保持 —
  張り替えても場所と横幅を崩さない)。

## 断念した代替案

- **w/h とも保持 (stretch)**: 縦横比が崩壊するので不可。
- **完全な bbox 保持 (fit)**: 画角違いで余白/欠けが出る。
  w 保持+h追従は「置き場所そのまま中身だけ新しく」の期待に最も近い。

## 影響

- dataUrl の LWW (`wclock['dataUrl']`) に乗るため P2P 経路でも収束。
- 置換前の画像は blob ストアに残るが `_imgSlim` 側の参照掃除は既存
  GC 規則に従う。
