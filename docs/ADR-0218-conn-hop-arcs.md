# ADR-0218: コネクタのホップ (交差ジャンプアーク)

## 状態

実装済み (v1.7.276)。

## 背景

フロー図でコネクタが交差すると視認性が落ちる。draw.io の
edgeStyle "jump" / 回路図の慣例では、上側の線が半円アークで
「飛び越し」を描く — Board には該当機能がなかった。

## 決定

ctx メニュー「ホップ (交差を飛び越す)」で `s.hop` をトグル。
直線・ウェイポイント・エルボーの各折線に対し、他コネクタ
の折線 (`_connPathPts`) との線分交差を毎フレーム計算し、
交差点で +法線方向に半円バルジ (R=7) を描く。端点から
3% 以内の接触は「結合」扱いでホップしない。曲線は対象外
(サンプリング折線への適用は見た目が不安定なため)。

- canvas: `_polylineHop` (stroke パス構築)
- SVG: `_hopPathD` (同一幾何の `d` 文字列) — 両者共通の
  `_segIntT`/`_hopsFor` で交差を1回計算
- `state.style.hop` + copyStyle キーに追加 (ADR-0183 系の
  スタイル永続化に追随)
- undo は既存 `style` op、`hop` キーで完全可逆

## 断念した代替案

- **曲線にも適用**: ベジエを16分割した折線近似と実描画の
  誤差でアーク位置がずれて見える。対象外とした。
- **自動ホップ (全コネクタ)**: draw.io も opt-in で、全線に
  半円が出ると素朴な図でノイズになる。ctx トグルに留めた。

## 影響

- ラベル位置 (`_connPathPts` ベース)・ヒット判定・結合は
  不変 — レンダリングのみ。
- `hop` 1本あたり全コネクタ走査だが、コネクタ数は実用上
  少数で O(1) 相当。
