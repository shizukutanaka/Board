# ADR-0132: 曲線コネクタのベンドドラッグ (`s.cbend`)

## 状態

実装済み (v1.7.189)。

## 背景

曲線 (ADR-0068) の制御点は弦からの垂直オフセット 25% (上限80px)
固定 — 通したい場所にカーブを寄せる手段が無い。elbow には
ADR-0072 の trunk ドラッグがあるが、curve 側が未対応だった。

## 決定

- 新prop `s.cbend` — 弦の中点から法線方向への符号付きオフセット
  (px)。`null`/未設定なら従来の自動 25% ボウ。
- `_curveCtrl(e,bend)` に引数追加し、全8箇所の描画・ヒット・
  SVG・ミニマップ・ラベル経路が `s.cbend` を読む — `labelPos`
  ドラッグ (ADR-0117) は `_curveSegs` 経由で自動追従。
- ドラッグ: 選択中の曲線の頂点 (二次ベジエ t=0.5 点) を掴むと
  `dragKind='cbend'` — ポインタを弦の法線へ射影し `snapV` で
  グリッド吸着。コミットは style op、cancel は clone 復元。
- `resetRoute` が `cbend` をクリア。`flipShape` はミラーで
  符号反転 (キラリティ保持)。

## 断念した代替案

- **制御点を任意位置に**: 真の三次制御点 (cx,cy) は柔軟だが
  「カーブの強さ/向き」のほうが図形用途には直感的 — elbow の
  `bend` と同じ1パラメータ設計を踏襲。
- **曲線本体どこでも掴める**: 頂点掴取で十分 (elbow trunk と同じ
  発見可能性)。

## 影響

- `cbend` は style op + validPatch 経由で undo/同期済み。
- 肘の `s.bend` のフリップ未変換 (座標値) は別の既存ギャップ —
  本 ADR では `cbend` (符号のみ) を正しく処理するのみ。
