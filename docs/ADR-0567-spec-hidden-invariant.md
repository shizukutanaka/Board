# ADR-0567: spec.md へ非表示の選択不変条件を追記

## 状態
実装済み (v1.7.594) — ドキュメントのみ

## 背景
`visible:0` (hide/show、ADR-0137/0146) は spec.md の §5/§6 に未記載だった —
⌘⇧H キーマップ自体も欠落。さらに ADR-0566 で確定した不変条件
「非表示図形はいかなる選択経路 (マーキー/⌘A/検索/フレーム内容選択) にも入らず、
ctx「すべて表示」のみで復帰する」がどこにも書かれていなかった。

## 決定
spec.md §5 の編集機能一覧に非表示/再表示の項と選択不変条件を追記し、
§6 キーマップに ⌘⇧H を追加。実装側の変更はなし (0566 のコードは済)。

## 影響
- 仕様と実装の一致: 今後の選択経路追加時に不変条件の根拠が読める
