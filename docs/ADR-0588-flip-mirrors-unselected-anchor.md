# ADR-0588: 選択外コネクタの結合先反転でも aF/bF をミラーする

## 状態

実装済 (round297)。ADR-0584 の残穴修正。

## 背景

ADR-0584 で「コネクタと結合先が共に選択中」なら `aF`/`bF` を `1−f` へミラーするよう修正したが、「結合先のみ選択中でコネクタは選択外」の場合に残穴があった:

- 結合先 extent は反転中心 `c` まわりにミラーされ、extent 上の比率座標 `{fx,fy}` の意味が変わる (新 extent の `f` = 旧 extent の `1−f`)。
- コネクタ自身は反転しない (端点 `x1`/`x2` 不変) のに、アンカー比率が生のまま → 反転後に `{0,·}` が反対側の辺位置へ解釈され、視覚的に結合先の反対辺へ端点が跳ぶ。

## 決定

`doFlip` で `sel` 外のコネクタを走査 (`_mC`): `a`/`b` が `flipIds` にあるものを収集し、同じ分数ミラーを適用。before/after にも同梱 — op の整合 (undo・ピア同期) を保つため、ADR-0586 と同じ構造。

## 影響

- 結合先だけを選んで flip した時も、非選択コネクタのアンカーが同じワールド点に留まる。
- 結合先が未反転 (未選択/ロック) なら不変 — `_selUL` がロックを排除済み。
- テスト: 未選択コネクタ `aF.fx:0→1` on `doFlip('h')` + undo 復元。
