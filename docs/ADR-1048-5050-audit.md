# ADR-1048: 50/50 audit — strengths, weaknesses, improvement surface

Date: 2026-10-05. Round797 (「長所短所をそれぞれ50」+ イーロン・マスク思考法/ソクラテス問答法 lens).

Method: first-principles interrogation of the product's core assumptions (「WHY single-file? WHY op-log? WHY LWW?」), then a grounded inventory — every item cites the mechanism that makes it true, not a vibe. Weaknesses are ordered roughly by user-visible impact, not by how ugly the code is.

## Socratic challenge of the founding assumptions

| Question | Assumption tested | Verdict |
|---|---|---|
| WHY one HTML file? | "0-second start, no install" is the product. A build step would buy tooling and lose the product. | Keep. The byte ceiling (557,056B raw) is the real budget — guard that, not the file count. |
| WHY op-log + per-property LWW instead of a shared CRDT document? | Full Yjs-style CRDT would buy text-merge and lose the zero-dep constraint + wire transparency (every op is inspectable JSON). | Keep. True gap: whole-string LWW on text (see W19). A narrow RGA for `s.text` is feasible without a doc CRDT. |
| WHY dual transport (BroadcastChannel + WebRTC)? | BC gives same-origin multi-tab sync for free; RTC gives cross-machine. The kind×transport matrix (ADR-0988) bounds what each may carry. | Keep, but note the trust boundary is the *content* of a message, never the transport (see W9–W16). |
| WHY in-memory dedup (seenOps) only? | A reload loses dedup memory — but every op is idempotent or tomb-gated, so re-application converges anyway (ADR-0655). | Keep — converge-by-construction beats persisted dedup. |
| WHY fingerprint (not hash) for image content addressing? | `_imgKey` reads 5 byte ranges for O(1) keying; a real hash is O(n) per read. Collisions were made observable instead (`_ik` byte-verify, ADR-1040/1047). | Keep — the verify closes the failure mode at read time, cheaper than hashing every ingest. |
| WHY manual paste signaling for RTC? | A signaling server would buy convenience and lose "zero infra / private by default". | Keep. The real UX gap is invite discoverability, not the transport. |
| WHY docs as ADRs instead of types? | No build = no TypeScript. The enforcement layer is test.mjs pins + contract ADRs. | Working, but pins are name-fragile (W5). Accept as the cost of zero-dep. |

## Strengths (50)

1. **Zero-install single file** — `index.html` runs from `file://`, no build, no deps, no account.
2. **Fully offline-capable** — Persist (IndexedDB) + real `sw.js` (ADR-1025).
3. **Every mutation is an op** — one funnel `_apply`/`_rcOp` feeds undo, wire broadcast, and damage tracking.
4. **Per-property LWW via `wclock`** — concurrent edits to different props never clobber each other.
5. **Existence clocks (`_born`/`_del`)** — tombstones stop stale add/snapshot resurrection (ADR-0734–0738).
6. **Idempotent apply + `seenOps` dedup** — re-delivered ops are free.
7. **Dedup-stamp eviction on apply failure** (ADR-1026) — a thrown apply doesn't wedge the op forever.
8. **wclock sanitize `_wK`/`_wR`/`_wAdopt`** — proto keys, structural keys, and junk clocks can't poison arbitration (ADR-1039).
9. **Structural keys (`pg`/`frac`/`groupId`) excluded from LWW** — mirror-image strip on send and intake (ADR-0912–0919).
10. **Intake bounds everywhere** — ids ≤64, coords bounded, ts ≤ wall+5min, prop weight ≤6KB (ADR-0788–0799 cluster).
11. **`validShape`/`validPatch`/`validClock`** — shape/type/clock validation is centralized, reused by importers.
12. **Envelope↔op clock binding** (ADR-0931/0932) — an op can't carry another peer's clock.
13. **Share-link payload caps + inflate guard** — deflate bombs rejected at the hash (ADR-0039/0325).
14. **Content-addressed image store** — dataUrl bytes live in `imgs` keyed by `_imgKey`, shapes carry `img:k` refs (ADR-0031/0069).
15. **Fingerprint-collision byte verify** — `_ik` check on `getImg` and the minimap reader (ADR-1040/1047).
16. **`_imgSent` byte+count bound** — the answer store stays able to answer imgq (ADR-0842/1045).
17. **`_imgPending` FIFO waitlist + straggler rescan** — parked refs heal or expire, never silently wedge (ADR-0629/0985/1046).
18. **Per-(key,sender) reassembly slots** — concurrent img/frag streams can't splice (ADR-0469/0781/1038).
19. **`_dcQ` backpressure queue** — drops >256KiB sends, resets on dc.onclose, can't poison (ADR-0432/0438/0446).
20. **Presence lifecycle is complete** — reap + bye + onclose + `rtc:` synthetic-row merge (ADR-1032).
21. **Selection presence dedup carries `curPg`** — page switches resend; dedup can't starve (ADR-0680/1031).
22. **`Net.init` resets every room-scoped buffer** — join state, reassembly, presence, img transfer, causal markers (ADR-1030).
23. **Join handshake is bounded** — sync-req bounded retry + responder election excluding the asker (ADR-0475/0465).
24. **Kind×transport gating** — RTC intake rejects BC-only kinds and vice versa (ADR-0986/0987/0988).
25. **'replace' converges over the wire** — wholesale swaps sync peers with a causal marker ordering (ADR-0613–0617).
26. **'clear' translates to `replace`(after:[])** — board wipe converges, not local-only (ADR-0626).
27. **Undo-wire inverse ops** — undo/redo propagate to peers with the wclock snapshot for correct arbitration (ADR-0443/0721).
28. **Locked parity** — undo/redo/remote all respect `s.locked` (ADR-0711–0716, 0760).
29. **Mid-gesture remote writes survive orig-restore** — remote lock→revert doesn't clobber the peer's write (ADR-0964/0969/0971).
30. **Key-repeat coalescing** (`_nug`) — held arrows/[ ]/rotate fold into one op, net-zero runs discarded (ADR-0957–0961).
31. **Erase batch is invisible but serialized** — `_shWB` union keeps mid-erase members in saves/snapshots/exports (ADR-1021).
32. **Hidden flush folds open editors** — uncommitted text lands in the doc before save (ADR-1022).
33. **Dirty-flag funnel** — every mutation path reaches `_md(!0)`, so `flushIfHidden` can't skip a live change.
34. **`:prev` backup + failure surfacing** — destructive swaps snapshot first and report write failure (ADR-0004/1028).
35. **`restoreBackup` rides `_repC`** — restore gets undo + broadcast + born stamps like a normal commit.
36. **Multi-page is real** — `s.pg` membership, page-scoped selection/export/presence/search, tab strip, PgUp/PgDn.
37. **Name renames converge** — `docName`/`pageName` arbitrate via `(ts,writer)` total order (ADR-0698/0699/1024).
38. **Selection hygiene** — every removal/swap/hide path drops dead ids (ADR-0623, 0954, 1010).
39. **Hidden parity** — hidden shapes vanish from draw/select/export/minimap/halo/search consistently.
40. **Gesture lifecycle funnel** — cancel reaches `_ptrReset`/pinch/`_pointers`/touch state on every path (blur/hidden/pagehide/present).
41. **Transient chrome drops on blur** — measure guide, quick-conn hover, eraser halo (ADR-1008/1009).
42. **Per-shape draw isolation** — one bad shape can't kill the frame; ctx state restored on throw (ADR-0601/1001).
43. **Spatial grid + `_gridVer` invalidation** — draw culling, hit-testing, snap all share one index.
44. **Minimap is a `_gridVer`-keyed bitmap** — theme/contrast flips invalidate via `_tTk` (ADR-0852).
45. **Wholesale-swap purge completeness** — `_pcC` clears per-shape caches and re-parks surviving img refs (ADR-0985).
46. **Real-path event testing** — test.mjs dispatches synthesized pointer/key sequences through the real listeners (ADR-0641).
47. **Import breadth** — .board/.drawio/.excalidraw/SVG/text/TSV, all through `validShape` intake.
48. **Export parity** — PNG/SVG/.board/.excalidraw/.drawio, selection-scoped and page-scoped.
49. **SR mirror + announce coverage** — DOM mirror list, peer join/leave, page adopts, hidden announce.
50. **The audit discipline itself** — ~50 ADRs of convergence/lifecycle invariants pinned in the local gate; divergence fixes shipped, clean audits recorded.

## Weaknesses (50)

1. **10,296-line single file** — review, navigation, and merge resolution all scale badly.
2. **No modules/build** — no tree-shaking; dead code is found by audit sweeps, not tooling.
3. **No CI** — `node test.mjs` is a local gate; nothing auto-blocks a bad push.
4. **Most pins are `html.includes` source strings** — they freeze the code's text, not its behavior; a refactor that keeps behavior but renames breaks the pin.
5. **Pin fragility on renames** — a shorthand fold touching a pinned token silently kills the assertion's meaning.
6. **Byte ceiling is a guideline** — rounds buy headroom by deleting comments, which erodes S8's cost the other way.
7. **Comment-tail reclaim creates severed fragments** — three repair sweeps (ADR-0849/0851/0854) were needed.
8. **Dense shorthand idiom** (`_mP`, `_du`, `_iS`…) — high onboarding cost; the map lives in the reader's head.
9. **Wire ops are unauthenticated** — any reach of BC/DC lets a peer inject ops; intake bounds cap the blast radius but not the forgery itself.
10. **Presence is fully trusted input** — forged cursor/avatar/selection render for other users.
11. **Peer ids are self-asserted** — no impersonation detection; `rtc:` forgery is only merged at `_pk`.
12. **`_imgKey` is a fingerprint, not a hash** — deterministic sampled ranges; a crafted pair collides (mitigated at read, not prevented).
13. **`_ik` verify is reference equality** — byte-identical but distinct dataUrl strings still miss the cache.
14. **E2E encryption covers only share links** — live wire ops are plaintext inside the room.
15. **BroadcastChannel is same-origin-wide** — any other tab on the origin can inject into the room.
16. **Manual RTC paste can't detect MITM rewriting** of the offer/answer.
17. **`sw.js` is a no-op on `file://`** — real PWA install still requires http(s) hosting.
18. **Undo stack is local-only** — undoing across a peer's concurrent edits is defined (inverse wire op) but reads arbitrarily to the user.
19. **Text edits are whole-string LWW** — two people editing one text shape clobber each other entirely.
20. **No op payload compression** — large patches/moves send full JSON on every commit.
21. **Join snapshot is whole-board serialize** — no delta sync; a huge board's first sync is one big transfer.
22. **Persistence rewrites the doc record** — no WAL/incremental; save cost scales with doc size.
23. **Cursor paint is O(peers)/frame** — presence send is throttled but render isn't.
24. **`_dcQ` has no priority classes** — presence bursts can delay ops in the same queue.
25. **60s imgq heal window** — a blob slower than that parks forever unless a straggler rescan catches it (probabilistic).
26. **`seenOps` lives only in memory** — reload re-applies; safe by idempotence but wasteful on reconnect storms.
27. **Tombstone retention is bounded by memory pressure**, not by a documented horizon — very old deletes can theoretically resurrect after tomb eviction.
28. **`replace`/`clear` ship the full shape set** — giant boards produce giant ops (only the opc fragmenter saves them).
29. **Per-page shape bound is implicit** — `SHARE_MAX_SHAPES` is global; per-page limits are unspoken.
30. **Density-adaptive grid can degenerate** — extreme size mixes skew the cell size for everyone.
31. **Overlay chrome mostly repaints whole** — local damage is implemented for gestures only.
32. **Desktop-first layout** — mobile gets touch handlers and the tab strip, not a density rethink.
33. **Shortcut discoverability** — everything lives behind the `?` overlay; no contextual hints.
34. **i18n is ja/en only** — adding a language is hand-editing `T.k`.
35. **SR mirror is a flat list** — it conveys order, not the spatial layout a sighted user sees.
36. **Color-vision support is two themes + contrast query** — no palette validation.
37. **Pen smoothing is RDP+prediction only** — no spline/fairing pass for shaky input.
38. **Groups are single-level (`groupId` is scalar)** — no nested grouping.
39. **Connector binding is endpoint-only** — no edge-midpoint or multi-point binds.
40. **Frames own members by move cascade** — frames don't have independent z-order/undo semantics.
41. **PNG/SVG export rasterizes synchronously** — a huge board blocks the tab.
42. **drawio/excalidraw fidelity is whack-a-mole** — each prop needs a hand-mapped round-trip; unknown props drop silently.
43. **Import is replace-shaped** — no merge-into-existing-board import.
44. **Share links hit URL limits** — big boards can't be link-shared at all (RTC only).
45. **No peer display names** — presence is avatar color + letter, hard to address a person.
46. **No read-only role** — every room member is an editor; sharing a link shares write access.
47. **No telemetry/error reporting** — production failures surface only if a user reports them.
48. **No op-replay/time-travel UI** — the op-log exists but can't be scrubbed back through.
49. **Docs↔code sync is manual** — architecture.md drifts until a sync ADR repairs it.
50. **Contracts are docs+pins, not types** — adding a new op/field is checklist discipline, not compiler enforcement.

## Improvement candidates (ranked)

- **P0 (correctness/data-loss risk)**
  - a. First-join progress affordance: a large board's initial snapshot currently looks like a hang — surface transfer progress or a "syncing" state.
  - b. Make the 60s imgq expiry *observable*: a parked image that heals late should render on arrival (today it can stay a placeholder until an unrelated invalidation).
- **P1 (major-function depth)**
  - a. CI: one GitHub Actions job running `node test.mjs` — the local gate exists, just run it.
  - b. Delta snapshot sync on join (send only shapes/ops newer than the asker's causal marker).
  - c. Wire op authentication: HMAC over a room secret in the invite link — the only real fix for W9/W15.
- **P2 (quality)**
  - a. Per-character text merge (narrow RGA on `s.text`) to close W19.
  - b. Two-class `_dcQ` (ops ahead of presence).
  - c. Merge-mode import (add onto current board instead of replace).
- **P3 (UX)**
  - a. Read-only share links (a `?ro` flag gating input).
  - b. Peer display names in presence.
  - c. Contextual shortcut hints on tool hover.
- **P4 (optimization, only if P0–P3 are empty)**
  - a. JSDoc types on the wire-op envelope (type-checks the contract without a build).
  - b. Op payload compaction (short keys already exist; batch-diff on move).
  - c. Off-main-thread export render (OffscreenCanvas where available).

Next round's axis, pending the next おまかせ: P0-a (join-progress affordance) or P2-b (queue priority) — both are small and close real UX gaps the audit surfaced.
