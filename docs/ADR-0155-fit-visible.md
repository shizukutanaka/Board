# ADR-0155: fitToContent は可視図形のみにフィット

## 状態

実装済み (v1.7.213)。

## 背景

`fitToContent` (⇧1 / ctx「全体を表示」) と起動ガード
`_fitIfEmptyView` は `G.bboxAll(state.shapes)` で全図形の bbox
を取る — 非表示図形を含む。大部分を非表示にした盤面で ⇧1
すると、見えないものに合わせて空領域までズームアウトする。

## 決定

- 両関数で `state.shapes.filter(s=>s.visible!==0)` を優先。
- 全件非表示の場合は全図形へフォールバック (隠れたコンテンツ
  位置への誘導は「見失い防止」という関数本来の目的に沿う)。

## 断念した代替案

- **非表示を完全無視 (フォールバック無し)**: 全件非表示時に
  zoomReset すると「盤面の位置」そのものも失われる。

## 影響

- フィット挙動のみ。
