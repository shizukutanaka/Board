# ADR-0341: 回転シェイプのリサイズカーソルを角度に追従

## 状態
承認 — round70

## 背景
`handleCursor` はハンドル id を軸並行の CSS カーソル
(`nwse/nesw/ns/ew-resize`) に固定対応させていたため、回転シェイプ
ではカーソル矢印が実際の伸縮方向とズレていた
(`docs/architecture.md` 残課題)。

## 決定
ハンドルの基底角 (nw/se=135°, ne/sw=45°, n/s=90°, e/w=0°) に
`s.rotate` を加え、双方向軸として mod 180 → 45° 単位で最寄りの
8方位カーソルに量子化。単一選択の hover 経路に `onlySel.rotate`
を渡す (複数選択は既存の非回転ガード内で据え置き)。

## 断念した代替案
- CSS `cursor: url(動的SVG)` で任意角カーソル — 生成負荷と互換性の
  ため採用せず (標準8方位で十分)。
- ハンドル当たり判定の座標系変更 — 無関係、カーソルのみ。
