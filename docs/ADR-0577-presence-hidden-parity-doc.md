# ADR-0577: 仕様・設計書へのプレゼンス hidden parity 同期

## 状態
実装済み (v1.7.604)

## 背景
ADR-0566/0568 の「非表示図形は選択されない」不変条件はローカル選択の話として
architecture.md / spec.md に記録されていたが、ADR-0576 で同一規則が描画系
(ピア選択アウトライン) にも拡張された。文書側にその旨が未反映だった。

## 決定
- architecture.md の hidden parity 節に `drawPeerSelections` の `_hd` フィルタを追記
- spec.md §5 の非表示規則にプレゼンス描画の除外を明記
- test.mjs に `_hd` ガードのソースピンを追加

## 影響
- 非表示規則が「ローカル選択 + リモートプレゼンス描画」の両面で文書化され、
  将来の別描画経路追加時のレビュー基準が明確になった
