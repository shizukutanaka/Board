# ADR-0046: ペンストロークのアウトライン塗り (可変線幅の union-of-primitives)

- 日付: 2026-09-23
- 状態: 承認
- 関連: ADR-0029 (draft 増分スタンプ), `docs/research-improvements.md` §項目B
  「filled-outline パス … perfect-freehand の本来の意義は outline 化」

## 背景

ペンは `penWidths()` で頂点ごとの太さを推定し (筆圧 or 速度プロキシ)、
セグメントごとに `lineWidth` を変えて二次曲線を打っていた。round cap/join で
継ぎ目を誤魔化しているが、研究文書が指摘する通り「区間境界に僅かなギャップが
見える可能性」があり、両端も定形 (round) でしかない — テーパーのある
自然な筆跡には outline 化が要る。

## 決定

ストロークを **セグメント台形 + 頂点円盤の和集合の塗り** として描く:

- 台形 quad(i): 線分 p[i-1]→p[i] の法線方向に半径 r[i-1],r[i] で張る四角形。
- 円盤 disc(i): 頂点 p[i] に半径 r[i] の円 — 台形同士の関節を埋める。
- 全プリミティブは凸かつ同一巻き方向なので、nonzero 塗りで和集合が必ず
  塗られる (境界をなぞる outline 方式の急カーブ自己交差は原理的にない)。
- `r[i]=w[i]/2×先端テーパー(i)×末端テーパー(n-1-i)`。`PEN_TAPER=8` サンプル
  かけて 0.15→1 にランプ — 筆跡の両端が自然に細る。
- **append-only 設計**: quad(i) と disc(i-1) を「インデックス i が安定したら
  焼く」規則にすると、ADR-0029 の増分スタンプがそのまま使える。
  末端テーパーは常に生端からの距離に依存するため **焼き込み境界を n-9 に**
  (幅安定 n-3 ∪ テーパー安定 n-9)。スタンプ部と生 tail の分割は全プリミティブ
  集合の排他的分割なので、コミット後の見た目と完全一致する。
- `drawPen` (コミット済み) / `drawPenDraft` (ドラフト) / SVG エクスポートの
  3経路は全て同一プリミティブ集合 → 表示=出力パリティ維持。
  SVG は巻き方向の保守を避けるため `<g fill>` + 台形 path + `<circle>` 要素の
  素直な和集合で表現 (union は要素合成で自明)。

## 断念した代替案

- **境界なぞり outline (perfect-freehand 本家方式)**: 左右オフセット折線を
  逆順に繋ぐ単一パス。頂点数は半分だが (a) ヘアピン急カーブで自己交差し
  nonzero 塗りの穴が出得る、(b) prefix の境界は append-only でないため
  ADR-0029 スタンプと両立しない — コミット済みとドラフトの幾何がずれる。
- **生 polyline 上の outline + quadratic 平滑の廃止**: 現在の見た目は
  midpoint-quadratic 平滑済み。プリミティブを raw pts 上に置いても
  頂点円盤が角を丸めてくれるので十分滑らか (perfect-freehand も生点入力)。
- **末端テーパーを焼き込みに含める**: n-1-i が大きくなると係数が変わるため
  不可 — 生 tail に残すことで解決 (上記)。

## 影響

- 見た目: セグメント継ぎ目のギャップ解消 + 両端の自然なテーパー。
- `_penCache` (ADR-0018)・`_penRes`・`_inkD` スタンプ構造は不変。
- `penWidths` は不変 (r=w/2 のみ) — テーパーは `_penTaperI/_penTaperE`。
- コスト: コミット済みは 1 fill/(2n-1) subpaths (旧: n/2 stroke 呼出) で
  同等以下。ドラフトは tail が ~9 プリミティブ/フレーム (旧 ~3 セグメント)。
- test.mjs: presence checks を新機構に更新、rec mock は fill() を計数。
