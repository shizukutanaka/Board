# ADR-0107: グリッドに整列 (ctx「Tidy up」)

## 状態

実装済み (v1.7.165)。

## 背景

バラバラに置かれた選択群を一括レイアウトする機能が hspace/
vspace (1軸整列) しか無い — Figma の「Tidy up」相当の2軸
リフローが欲しい。

## 決定

- `doAlign` に `dir:'tidy'` を追加 (既存の unit 機構 — frame/
  group を単位として扱う — をそのまま再利用)。
- 読み順 (y→x) ソート、`cols=ceil(sqrt(n))` の正方形近似グリッド。
  列幅はその列の最大幅、行高はその行の最大高 +32px ギャップで
  行先頭から row-major 配置。
- ctx メニュー `ctxTidy` (選択3以上)。

## 断念した代替案

- **等間隔セル固定**: セルを最大形状に統一すると小さい形状の
  周りに空きが出すぎる — 列/行単位のピッチで可変に。
- **グループ分解**: unit 機構 (frame 包含・groupId) が既に正しい
  まとまりを提供 — 従来通り。

## 影響

- `align` op (dir:'tidy') で一括 undo、REMOTE_OPS 内なので
  共有同期も既存経路。
- `DIRS` ホワイトリストに 'tidy' 追加 (test 更新済)。
