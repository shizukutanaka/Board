# ADR-0192: 付箋の文字色 (s.stroke)

## 状態

実装済み (v1.7.250)。

## 背景

「設定可能だが描画されない」監査の残件 — 付箋選択中に stroke
スウォッチで `s.stroke` を設定できても、付箋のボーダーは
`rgba(0,0,0,.06)` 固定・本文は `#1E293B` 固定で、どちらも
`s.stroke` を読まなかった。

## 決定

`s.stroke` を付箋**本文色**に割当て (text 型で stroke=ink と同じ
語彙)。canvas 本文・下線/取消線・SVG `<text>` の3箇所が
`s.stroke||'#1E293B'` を使用。ボーダーは薄い影と一体の視覚規約
のため従来通り固定を維持。

## 断念した代替案

- **ボーダー色に割当**: 付箋の「線」はほぼ見えないため、線色を
  当てても効果が薄い。文字色として使う方がユーザの期待に近い。

## 影響

- `s.stroke` 未設定の付箋は不変。スタイルコピー/スポイトの
  stroke キーが付箋でも意味を持つようになる。
