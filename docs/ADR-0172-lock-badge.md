# ADR-0172: ロック選択の鍵バッジ

## 状態

実装済み (v1.7.230)。

## 背景

ロック済み図形を選択すると破線アウトラインのみ表示 — 「選択できたが
動かせない」状態の読み取りが弱い。draw.io は選択時に鍵アイコンを
表示してロックを明示する。

## 決定

`drawSelection` の `lockedSel` 分岐で、bbox 左上内側に 16×12 の
鍵バッジ (紙色ボディ + シャックル + キーホール) を描画。ハンドル
非表示は従来通り (ロック=編集不可の UI 規則)。スクリーン座標で
描くためズームに依らず一定サイズ。

## 断念した代替案

- **ダブル破線/色変更のみ**: 鍵アイコンの方が意味的に明確で
  draw.io parity。

## 影響

- オーバーレイ描画のみ。シーン・状態・履歴に影響なし。
