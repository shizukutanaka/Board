# ADR-0610: roundShapesForExport の pts 丸め二重処理を除去

## 状態
実装済 (v1.7.637)

## 背景
`roundShapesForExport` が `o.pts` を連続2回 `map` で丸めていた — 2回目は
既に丸め済みの配列への同一処理で完全なデッド重複 (おそらく 0090 系の
編集で残った行)。export/copy-board/share の全経路で余計な配列走査と
~90B のソースを消費していた。

## 決定
2 行目を除去。丸めの結果・決定性は不変 (冪等)。

## 影響
- ~90B 回収、エクスポート経路の不要な O(pts) 走査を解消
- 振る舞い変更なし
