# ADR-0174: ctx メニューの不透明度巡回

## 状態

実装済み (v1.7.232)。

## 背景

不透明度は数字キー (0-9, ADR-0167) でのみ到達可能 — キーボードを
知らない・使えないユーザー (タッチ) には発見経路が無い。draw.io/
Figma はパネルに不透明度スライダを置くが、Board の ctx メニューは
巡回項目の文法で同等の到達性を提供する。

## 決定

ctx「不透明度 (巡回)」— 任意の非ロック選択で表示。巡回レベルは
`1 → 0.7 → 0.4 → 0.1 → 1` (Figma の decimal step に倣う)。複数選択
時は先頭の非ロック図形の現値から次レベルを決め、全選択に一括適用
(選択間の不透明度が揃う)。非標準の現値は「次に小さいレベル」に
正規化。`applyStyleToSelection` 経由で style op → undo/sync 適合。

## 断念した代替案

- **スライダ UI**: ctx 巡回の文法と一貫しないため見送り (スタイル
  パネルの既存 opacity スライダが既に存在)。
- **選択ごとの相対増減**: 選択間の値が揃わず予測不能 — 絶対値
  一括適用の方が ctx 巡回の規則 (他項目も一律値) に一致。

## 影響

- `0-9` キーと同じ op 経路 — データ互換・undo 完全対応。
