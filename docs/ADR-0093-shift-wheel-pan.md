# ADR-0093: ⇧+ホイール = 水平パン

## 状態

実装済み (v1.7.151)。

## 背景

ホイールスクロールは `deltaX`/`deltaY` をそのままパンに使う。
マウスホイールは縦しか回せないため水平パン不可 — ⇧+wheel を
水平に割り当てるのは Figma/draw.io/OS 全体の慣例。

## 決定

- `wheelPx` のパン経路で `e.shiftKey && !e.deltaX` のとき
  `deltaY` を X 成分へ移す (deltaX を持つトラックパッドは素通し)。
- ctrl/meta+wheel (ズーム) 経路は d.y のみ読むため無影響。

## 断念した代替案

- **wheelPx 内でのリマップ**: ズーム経路も通るため、shift+ctrl+wheel
  で d.y が 0 になる副作用を避け、パン分岐でのみ変換。

## 影響

- マウスホイール + ⇧ で水平スクロール可能に。
- トラックパッドの deltaX + ⇧ は従来通り (両軸パン)。
