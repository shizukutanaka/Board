# ADR-0383: RTC スナップショットのチャンク化

## 状態
採用 (v1.7.426)

## 背景
`dc.onopen` は盤面スナップショットを**単一 `dc.send`** に載せていた。SCTP
メッセージ上限 (~256KB) を超える大盤面では send が TypeError で静寂失敗し、
参加側は何も同期されないまま — エラーも出ない (try/catch が飲む)。

## 決定
240KB 超のスナップショットは 'img' と同じ 64KB チャンク分割
(`{k:'snap',seq,n,data}`) に乗せ、受信側は単一の `_snapIn` 組立で再構成し
完成時に通常経路 `_onRecv` へ再投入。チャンク 96KB/n≤384/結合後 24MB の
既存ガードと同型の上限を適用。BroadcastChannel 経路は postMessage に実質
上限がないため非チャンクのまま。

## 断念した代替案
- 送信前にサイズを測ってトーストのみ: 失敗を見える化するが同期自体は失敗する
- `bufferedAmount` バックプレッシャ: 問題はメッセージサイズ上限で流量ではない
