# ADR-0206: コネクタ端点ドラッグの 45° 拘束 + ラベルエディタのフォント一致

## 状態

実装済み (v1.7.264)。

## 背景

コネクタ (line/arrow) の端点を掴んでドラッグすると自由配置のみ —
始点→終点ドラッグ描画時の Shift=45° 拘束 (contLineLike) と同じ
拘束が既存コネクタの端点移動には無く、水平/垂直配線の調整が難しかった。

またラベルエディタ入力欄が常に `12px` 固定で、シェイプの
`s.fontSize`/`s.italic` を反映していなかった (描画との不整合)。

## 決定

- `applyResize` の p1/p2 (コネクタ端点) パスで `shift` 時、固定端から
  45° 刻みへ投影 (contLineLike の uniform 拘束と同一数学)。
- ラベルエディタ入力フォントを `${hit.fontSize||12}px` + italic へ。

## 断念した代替案

- **軸のみ (H/V) 拘束**: 45° 拘束のほうが斜め線維持にも効き、
  新規描画と一貫。

## 影響

- Shift 無しの端点ドラッグは不変。拘束中は `sp` だけが書き換わる
  (bind 判定・readout は変換後座標で動作)。
