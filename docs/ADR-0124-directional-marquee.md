# ADR-0124: 方向付きマーキー (右ドラッグ=交差選択)

## 状態

実装済み (v1.7.181)。

## 背景

マーキーは厳密な包含のみ — 密集盤面で「触れた図形全部」を取る
標準慣例 (CAD/draw.io/Figma: 右→左ドラッグ = crossing 選択) が
無い。包含で届かない重なり形状を選ぶには個別クリックが必要。

## 決定

- ドラッグ方向でモード分岐: 左→右 (`m.x2>m.x1`) = 従来通り
  完全包含、右→左 (`m.x2<m.x1`) = bbox 交差 (touch) 選択。
- 実装は `endSelect` 内の1分岐 — グリッド候補抽出
  (`_gridRectCandidates`) は両モード共通でそのまま有効。

## 断念した代替案

- **修飾キー切替 (⇧で交差)**: ⇧ は既存の加算選択と衝突 —
  方向慣例は追加キーを要らず学習済みユーザに自然。
- **交差モードの視覚差分**: 現時点では行為のみ — tint 変更は
  必要に応じて後続で。

## 影響

- 右→左の包含は「触れた」意味に変わる — 従来どちら向きでも
  同じ結果だったユーザーへの振る舞い変更は意図的 (標準慣例)。
