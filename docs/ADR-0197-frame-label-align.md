# ADR-0197: フレームラベルの文字揃え

## 状態

実装済み (v1.7.255)。

## 背景

フレームラベルは左上 `s.x+6` 固定 — `s.label` キャリアとして
cycleTextAlign の対象だったが、フレームラベル自体は align を
読まず「設定可能だが描画されない」隙間が残った (ADR-0186/0188
の font と同型)。

## 決定

フレームラベルの canvas/SVG 両描画で `s.align` を適用
(left 既定 → center/right はフレーム幅基準)。cycleTextAlign/
ctxTextAlign ゲートに `s.type==='frame'` を追加 (ラベル未設定
でも常時描画のため)。600 ウェイト規約は維持。

## 断念した代替案

- **valign もフレームへ**: フレーム名は上端キャプションの
  約束 — 縦揃えは対象外。

## 影響

- `s.align` 未設定のフレームは不変。長いフレームでの中央揃え
  タイトルが可能に。
