# ADR-0111: フレームの内容を選択 (ctx メニュー)

## 状態

実装済み (v1.7.169)。

## 背景

フレーム内の中身だけをまとめて操作 (色変更・複製・削除) したい
とき、マーキーで囲むとフレーム自身や背景も拾ってしまう。
空間包含ルールは既に `withFrameChildren` にある。

## 決定

- `selectFrameContents()` — ctx `ctxSelContents` (frame 選択時)。
  `withFrameChildren` の包含判定で内包形状を列挙し、フレーム
  自身を除いた集合に選択を置換。`_announceSel` + 件数トースト。
- 空フレームは `selectTwo` 警告 (既存警告流用)。

## 断念した代替案

- **frame メタへのメンバ登録**: Board のフレームは純粋に空間的
  — メタ登録は不要かつ不整合源。判定を一元化する withFrameChildren
  の再利用が正しい。

## 影響

- 選択置換のみの純粋 UI op (undo 対象外)。
- 「フレームで動くもの」と「選択されるもの」が定義上一致する
  保証 (同一関数)。
