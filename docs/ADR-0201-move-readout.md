# ADR-0201: 移動ドラッグ中の X,Y リードアウト

## 状態

実装済み (v1.7.259)。

## 背景

`state.readout` (ADR-0064) の live ピルは回転角度・リサイズ寸法・
線長を表示するが、最も頻繁な移動ジェスチャでは何も表示されなかった。
Figma ではドラッグ中に選択の X/Y がパネルに反映される。

## 決定

`doMove` で選択群の union bbox を算出し、左上座標を
`${x}, ${y}` (丸め) でピル表示 — 位置は bbox 下端。G.bbox は
ADR-0019 の O(1) メモ化で per-move 追加コストは軽微。

## 断念した代替案

- **Δx,Δy 表示**: 開始位置が分からず絶対配置を見失う。
- **個々のシェイプ座標**: 複数選択時に意味を持たない → union 左上。

## 影響

- グリッド吸着との併用で数値確認しながら配置できる。
