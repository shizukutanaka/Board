# ADR-0212: コネクタラベルの行間 (lineH) 反映

## 状態

実装済み (v1.7.270)。

## 背景

ctx「行間」ゲートは `s.label` 保持のコネクタを既に含んでおり、
style op で `s.lineH` がコネクタに保存されていたが、描画側は
`fs*1.25` ハードコード — ADR-0210 の複数行化で行数が増えても
設定が絵に出ない「設定可能だが未描画」状態だった。

## 決定

canvas `llh`・SVG `lh2` を `fs*(s.lineH||1.25)` に変更 —
ボックスラベル (ADR-0188) と同一のフォールバック式。

## 断念した代替案

- なし (1行修正で正体不明の設定値が機能するだけの純粋な欠陥修正)。

## 影響

- `s.lineH` 設定のコネクタラベルが実際に行間変化。
  未設定は 1.25 で従来同一。
