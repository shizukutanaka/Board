# ADR-0152: グループリサイズで曲線ベンドが取り残されるバグ

## 状態

実装済み (v1.7.210)。

## 背景

`s.cbend` は弦の中点からの符号付き垂直オフセット (px)。
`_mapToBox` (複数選択リサイズ) は x1/y1/x2/y2/way/bend を写像
するが cbend を素通りさせていた — 縮小してもオフセットが絶対
px のまま残り、小さくなったコネクタに大きな弓なりが残った。

## 決定

- アフィン写像の閉形式で再計算: `cbend' = cbend·sx·sy·len/len'`。
  導出: `_curveCtrl` の制御点は `mid + n·b`、写像後の弦法線 n'
  へ逆投影すると sx·sy·len/len' に縮約する。
- 符号: ハンドルが反対側を跨いだ場合 sx·sy<0 となり、cbend が
  反転して曲線のキラリティが正しくミラーされる。

## 断念した代替案

- **制御点を写像して差分保存**: cbend の定義自体が法線方向の
  1スカラなので閉形式の方が単純・正確。

## 影響

- リサイズ済みコネクタの見た目のみ。undo は `align` op
  (before/after 両方に cbend 含む) で完全。
