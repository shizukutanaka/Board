# ADR-0134: z-order の ctx メニュー項目

## 状態

実装済み (v1.7.191)。

## 背景

`]`/`[`/⇧`]`/⇧`[` のz順操作はキーボード限定 — タッチでは
コンテキストメニュー (長押し、ADR-0006) が唯一の到達経路であり、
z順の変更がタッチ端末から不可能だった。

## 決定

- ctx に4項目追加: 最前面へ (⇧]) / 前面へ (]) / 背面へ ([) /
  最背面へ (⇧[) — 既存の `doBringFront` 等をそのまま呼ぶ。
- 選択時のみ表示 (他の選択依存項目と同じ `has&&` ゲート)。

## 断念した代替案

- **1項目の「重なり順」サブメニュー**: ctx はフラット構造 —
  サブメニュー機構を新設するほどではない。

## 影響

- キーボードショートカットは不変 — ctx は別経路の追加のみ。
