# ADR-0193: コネクタラベル背景に s.fill

## 状態

実装済み (v1.7.251)。

## 背景

コネクタラベルの pill 背景は `--paper` 固定 — fill スウォッチ/
スタイルコピーで `s.fill` を設定できても描画されない監査残件。
draw.io のエッジラベルは背景色を持てる。

## 決定

pill 背景を `s.fill||paper` に (canvas `_drawConnLabel` と SVG
`_connLabelSVG` の両方)。半透明 0.9 規約は維持。

## 断念した代替案

- **不透明にする**: 既存 pill の透過は下面コンテンツをわずかに
  透かす意図的規約 — 色を変えても透過は維持。

## 影響

- `s.fill` 未設定のコネクタは不変。これで「スウォッチで設定
  可能だが描画されない」プロパティの監査が完結。
