# ADR-0273: タブ区切りペースト → 付箋グリッド

## 状態
承認 — round40

## 背景
スプレッドシート/表からのコピーは `\n` 行 × `\t` 列の TSV。従来は単一の
text 図形として貼られ、セル単位の操作ができなかった。Whimsical/
draw.io はセルを付箋グリッドに展開する。

## 決定
text/plain ペーストの fallback 手前で、`\t` と `\n` を両方含む場合に
行×列の付箋グリッドを生成 (sw=160×sh=96、間隔16、盤面中央配置)。
空セルは付箋を作らない。一括 `addMany` で undo 1回。

## 断念した代替案
- CSV (カンマ区切り) — 文内カンマとの誤爆が多いため TSV のみ
  (スプレッドシートのネイティブコピー形式)。
- グリッド配置を既存 tidy/align へ委譲 — 初手から整列させる方が
  単純で見た目も良い。

## 影響
表データが編集可能な付箋ボードとして取り込める。1980 全緑。
