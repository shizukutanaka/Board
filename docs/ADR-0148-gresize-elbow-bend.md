# ADR-0148: グループリサイズ時のエルボー trunk 追従 (バグ修正)

## 状態

実装済み (v1.7.205)。

## 背景

ADR-0146/0147 と同種の第3弾: `_mapToBox` (複数選択リサイズ) が
`s.bend` をスケールしなかったため、elbow を含む選択群を
リサイズすると trunk が旧位置に残った。

## 決定

- `_mapToBox` の x1 分岐で、`orig` の trunk を評価し同じ
  アフィン写像 M で trunk 端点を写す — 軸平行スケーリングは
  trunk の向きを保つためスカラのまま表現可能 (縦 trunk →
  M(bend).x、横 trunk → M(bend).y)。

## 断念した代替案

- **斜め化への対応**: 軸平行スケールでは trunk は常に軸平行の
  まま — 考慮不要 (回転の 0146 とは異なり退化しない)。

## 影響

- 単一コネクタの端点リサイズ (p1/p2) は従来どおり trunk が
  その場に残る挙動 (draw.io 準拠) — 変更はグループリサイズのみ。
