# ADR-0597: ドラッグのダメージ矩形に束縛コネクタの掃引領域を含める

## 状態

実装済 (round306)。

## 背景

ADR-0026 の局所再描画は、ドラッグ対象図形の before/after bbox のみでダメージ矩形を
構成する。束縛コネクタ (`aF`/`bF`) は束縛先図形の extent から端点を動的解決するため、
束縛先が移動/リサイズ/回転するとコネクタの path も変化する — しかしコネクタ自身は
ドラッグ対象に含まれず、その掃引領域 (新旧 path の union) がダメージ矩形から
漏れていた。

結果: 遠くの図形へ結ばれたコネクタを持つ図形をドラッグすると、ダメージ外の旧 path
が残像として残る (次の全体 invalidate まで残留)。

## 決定

3 つのジェスチャドラッグで束縛コネクタの掃引領域を union する:

- `doMove`: `ptr.dragStartShapes` に束縛されたコネクタを `_dc` に収集 (変形前 bbox)、
  変形後の `_bb` と `_dmgPair` で union。
- `_gresizeDrag`: `ptr.gOrig` メンバーに束縛されたコネクタを同様に。
- `_grotDrag`: `ptr.gAnc` (束縛先回転で aF remap されるコネクタ) の orig clone `_bb(oc)`
  と live `_bb(sh)` を union。

いずれも `(aF&&a∈変形対象)||(bF&&b∈変形対象)` の判定で収集し、マージンは
`(size||2)+16` で既存形状と揃える。

## 影響

- 束縛コネクタが追従変化する全ドラッグ経路で残像が出ない。
- `_apply`/`applyRemote` の op ダメージは op の全 id の bbox を収穫する方式のため
  (束縛コネクタを書き換える op は `align`/`style` の before/after に含まれる) 非対象。
- テスト: 3 サイトの収集+union コードをソースピン。
