# ADR-0316: SVG 書き出しにも 🔗 バッジを描画

## 状態
承認 — round52

## 背景
🔗 リンクバッジ (ADR-0310) は canvas のみで、SVG 書き出し
(= PNG/PDF にも波及するレンダラ) には反映されていなかった。

## 決定
形状ループ末尾に `s.link&&s.w!=null` の `<text>` を1箇所追加 —
canvas と同じ右上位置・10px・`dominant-baseline="hanging"` で
コーナーアンカー、opacity 属性も同梱。

## 断念した代替案
- `<a xlink:href>` でクリック可能リンク — SVG ファイルを開く
  環境依存 + JS 実行環境なしでは機能しないため静的バッジに留めた。

## 影響
SVG 出力にリンク存在が視覚化。2024 全緑。
