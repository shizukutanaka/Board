# ADR-0128: ドラッグ中の Alt 押下で全スナップ抑制

## 状態

実装済み (v1.7.185)。

## 背景

グリッドスナップとオブジェクトスナップは常時 ON/OFF の切替のみ —
「このドラッグだけ吸着させたくない」ができない。draw.io は
「Alt を押しながらドラッグで全スナップ機能を無効化」が定番。

## 決定

- `moveDelta(wp,shift)` に `alt` 引数を追加 — Alt 押下中は
  `snapPt`/`snapV` (グリッド) と `objectSnap` の両方を素通しし、
  生のワールド座標で動く。
- 呼び出し経路 `doMove` / `endSelect` も `e.altKey` を伝播
  (コミット時に Alt を離すとスナップが再び効くのは意図的 —
  最終状態の直前スナップと整合)。

## 断念した代替案

- **修飾キーを他に**: Figma は制約系で Alt、draw.io はスナップ
  無効で Alt — Board は Alt+drag 複製と共存するが、複製ドラッグ中の
  Alt 継続押下も同じ意味 (draw.io と同挙動) なので衝突しない。
- **⇧に割当**: ⇧ は既に軸拘束 — 別修飾が必要。

## 影響

- リサイズ系の Alt (対称変形) には手を付けない — 移動のみの挙動変更。
