# ADR-0187: 付箋本文の縦揃え

## 状態

実装済み (v1.7.245)。

## 背景

付箋テキストは上端固定 (`s.y+pad`) — 縦に長い付箋で Excalidraw 式の
センター寄せや下揃えができない。`s.valign` (ADR-0179、画像キャプション
用) と同一語彙で表せる。

## 決定

`cycleVAlign` の対象に sticky を追加 — 専用サイクル
`[null,'middle','bottom']` (既定は現行の上揃え)。canvas 描画と
SVG export の両方でブロック位置を計算 (下線/取消線 y も追従)。
ctxVAlign の表示名を「縦揃え」に汎用化 (付箋はラベルではなく本文)。

## 断念した代替案

- **'top' も sticky サイクルに含める**: null と見た目が重複するため
  除外 — 4状態より3状態が巡回として自然。

## 影響

- 既存付箋 (valign 未設定) の表示は不変。`s.valign==='top'` が
  sticky に混入した場合も top として描画される (語彙共用の副産物)。
