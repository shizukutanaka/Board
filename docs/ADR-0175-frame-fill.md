# ADR-0175: フレームの塗り色

## 状態

実装済み (v1.7.233)。

## 背景

フレームの内側は常に半透明の固定色 — スタイル経路で `s.fill` を
設定できても描画が無視していた。Miro/draw.io のフレームは色付け
可能で、複数フレームの視覚的グルーピングに使える。

## 決定

canvas と SVG の両経路で `c.fillStyle=s.fill||'rgba(248,250,252,0.6)'`
(既定色は従来通り)。フレームは描画の第1パスで描かれるため、中身
の図形は引き続き全面に描かれる — 塗りで内容が隠れることはない。

## 断念した代替案

- **半透明化のみ強制 (fill へ常に alpha 付与)**: ユーザーが設定した
  色をそのまま尊重する方が style 体系と一致。フレームが先に描く
  ため alpha 化の必要もない。

## 影響

- `s.fill` 未設定のフレームは見た目不変。塗りボタン/スタイル
  コピーで既に設定可能だった値が視覚化されるだけ。
