# ADR-0143: Alt+click でエルボー trunk を中央へ

## 状態

実装済み (v1.7.200)。

## 背景

elbow の trunk ドラッグ (ADR-0072) で移した `s.bend` を元に戻す
手段がルートリセット (全クリア) のみだった。ADR-0141 の
「⌥click = ルート変更の個別解除」パターンを bend にも適用。

## 決定

- 選択中 elbow の trunk への Alt+pointerdown はドラッグ開始では
  なく `s.bend` 削除 (自動中央位置に復帰)。style op → undo一発。
- `bend` が無い時は従来通りドラッグ開始 (二重リセットを防ぐ)。

## 断念した代替案

- **dblclick リセット**: ラベル編集と衝突 (ADR-0141 と同じ判断)。
- **ctx 項目追加**: 頂点/トランク単位の文脈メニューは hit 状態の
  引き回しが要り複雑 — Alt+click で十分。

## 影響

- `resetRoute` の挙動は不変 (引き続き全クリア)。
