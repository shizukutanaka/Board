# ADR-0381: コネクタを結合先の名前で検索可能に

## 状態
採用 (v1.7.426)

## 背景
`_sqMatches` の検索対象は `label+text+type+link` — コネクタ自身の属性のみ。
「Loginボタンに入っている矢印」を "login" で探すとヒットしない — 結合は
コネクタのアイデンティティなのに検索チャネルに出ていなかった
(ADR-0380 の SR アナウンスと同じギャップの検索版)。

## 決定
`_conn(s.type)` のみ、結合先 `s.a`/`s.b` の `label+text+type` を haystack に追加。
`byId` で解決 (`_idIndex` 経由 O(1)) — コネクタ以外は従来通りの式なので
非コネクタの検索コストは不変。結果キャッシュ `{_gridVer,_sq}` はそのまま効く。

## 断念した代替案
- `describeShape` 全文を結合先に適用する案 — 再帰・コスト・過剰一致の面で過剰
