# ADR-0177: 消しゴムのホバーハイライト

## 状態

実装済み (v1.7.235)。

## 背景

消しゴムは pointerdown 即削除 — 狙いを外した時の取り返しは undo
頼みだった。Excalidraw は消去対象をホバー時に赤枠で予告する。

## 決定

- `state.tool==='eraser'` かつ非ドラッグの pointermove で
  `pickTop(wp)` → `state._ehov` に対象 id を保持 (署名比較で変化時
  のみ `invalidateOverlay` — pickTop は ADR-0032 でグリッド加速済み)。
- オーバーレイに `#EF4444` 破線 bbox を描画。ロック図形は対象外
  (消去不能と一貫)。`pickTool` で `_ehov` をリセット。

## 断念した代替案

- **半透明赤フィル**: 図形の塗りを隠してしまう — 破線枠の方が
  ターゲットを読みやすい。

## 影響

- 状態・履歴に影響なし (オーバーレイのみ)。消しゴムツール以外の
  ホバー経路は不変。
