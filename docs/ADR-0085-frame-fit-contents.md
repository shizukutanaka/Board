# ADR-0085: フレームをコンテンツに合わせる (Fit to contents)

## 状態

実装済み (v1.7.143)。

## 背景

frame は内包シェイプのコンテナとして動くが、中身を追加・移動すると
フレーム矩形が余白過多 / はみ出しのまま残る。draw.io のコンテナに
ある「コンテンツに合わせてリサイズ」が無い — 手で四隅を直すしかない。

## 決定

- `fitFrames()`: 選択中の未ロック frame 各々について、**完全に内側**に
  収まるシェイプ (frame メンバシップと同一の包含判定) の union bbox を
  計算し、12px padding を付けて `x/y/w/h` を更新。空の frame・差分無し
  はスキップ。
- `align` op (`dir:'framefit'`) で before/after を記録 — 複数 frame を
  1 op で原子化、undo 一発。DIRS に 'framefit' を追加。
- ctx メニューに `ctxFrameFit` — 選択中に未ロック frame がある時だけ表示。

## 断念した代替案

- **frame は常時 auto-fit**: 故意に余白を取る用途 (章立て見出し帯など)
  を潰す。明示コマンドのみ。
- **`upd` op 連発**: frame 複数選択時に op が分かれ undo が複数回に
  なる。align の batch patch がそのまま使える。
- **部分的に重なるシェイプも含める**: 「完全に内側」はメンバ判定と
  同じ規則。半重なりを含めると意図しない拡大になる。

## 影響

- 空 frame は no-op (中身が無ければ基準が無い)。
- frame label の描画位置は矩形左上基準のため追従する。
