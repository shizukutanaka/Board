# ADR-0385: dc.onclose で半受信スナップショットを破棄

## 状態
採用 (v1.7.428)

## 背景
ADR-0383 の `'snap'` チャンクは join 毎に1組立 `_snapIn` を使う。転送途中で
接続が切れると parts が残置し、次の join で新スナップショットと同じ n なら
新旧チャンクが混入して `_JP` 失敗 → 同期が 1 回分失われる。

## 決定
`dc.onclose` で `this._snapIn=null`。`_imgChunks`/`_imgPending` は
コンテンツハッシュ鍵で冪等なため据置。

## 影響
再接続時のスナップショット再受信が常にクリーン。
